## 摘要
我们通过实验和系统级模拟表明，通过使用电路级补偿技术和算法级别的批归一化重新校准，可以成功缓解保持损失对推理精度下降的影响。实验在标准65 nm CMOS中制造的单多晶硅浮栅模拟非易失性存储器阵列上进行，用于模拟内存计算。我们使用通过实验校准的保持损失统计模型来评估对VGG-10/CIFAR-10和WideResNet-28-10/CIFAR-100等神经网络模型的系统级影响。我们表明，在编程后60天，组合缓解技术能够在2-4%的范围内恢复基线推理精度。

## Abstract
We show with experiments and system-level simulations that it is possible to successfully mitigate the impact of retention loss on inference accuracy degradation by using both circuit-level compensation techniques and batch normalization recalibration at the algorithmic level. Experiments are performed on a single-poly floating-gate (FG) analog non-volatile memory array for analog in-memory computing fabricated in a standard 65 nm CMOS. We use a model of retention-loss statistics calibrated with experiments to evaluate the system-level impact on neural network models such as VGG-10/CIFAR-10 and WideResNet-28-10/CIFAR-100. We show that, after 60 days since programming, combined mitigation techniques enable to recover the baseline inference accuracy within 2-4%

## 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：模拟向量-矩阵乘法（VMM）是模拟内存计算（AIMC）的核心架构，矩阵权重以模拟非易失性存储单元的物理状态（如电荷、电阻、相态）直接实例化在存储阵列中。此类方案通过减少数据搬运、利用亚阈值区工作，获得显著的能效提升。
- **核心问题**：浮栅（FG）非易失性存储器件存在**电荷保持损失（retention loss）**问题——随着时间推移，浮栅上存储的电荷逐渐流失，导致编程电流偏移、权重漂移，最终造成神经网络推理精度下降。
- **与数字存储的区别**：数字非易失性存储中，电荷丢失可用“误码率+纠错码”统一衡量；但在模拟存储中，多级状态直接代表突触权重，电荷丢失是**连续量的扰动**，会直接污染矩阵运算结果，因此必须从**器件-系统联合视角**评估和缓解。
- **研究意义**：本文面向浮栅模拟存内计算的实际部署需求，提出一种结合**电路级补偿**与**算法级（批量归一化重校准）**的组合缓解方案，证明在标准65 nm CMOS工艺下，可在编程后60天内将推理精度损失控制在基线水平的2%–4%以内，为浮栅模拟神经形态芯片的长期可靠运行提供了可行路径。

## 二、方法论：核心思想、关键技术细节与流程

### 核心思想
浮栅电荷损失可分解为两大部分：
1. **系统性（平均）漂移成分**——所有器件共有的平均电流漂移趋势；
2. **随机性（器件间）波动成分**——从器件到器件、从一次实现到下一次实现随机变化的零均值扰动。

针对两类成分，采用**互补的两级缓解策略**：
- **Vread补偿（VRC，电路级）**：调节读取电压，抵消系统性电流漂移；
- **Batch Normalization Recalibration（BNR，算法级）**：重新估计批归一化层的均值和方差，抵消随机扰动造成的激活分布偏移。

### 关键技术与实现细节

1. **器件与阵列架构**：
   - 采用TSMC 65 nm单多晶硅（single-poly）CMOS工艺，2.5 V I/O nMOS器件，W/L = 240 nm/180 nm；
   - 1T-1FG交叉阵列结构：每个单元由存储权重的浮栅晶体管与选择晶体管串联组成，选择晶体管抑制编程干扰；
   - 单元面积为0.88 μm × 0.64 μm；
   - 采用**时域乘法**方案：字线激活时间正比于输入，FG晶体管工作在饱和区，漏极-源极电压为Vread，栅极-源极电压为VGS = kVread + QFG/CΣ，其中k = CDS/CΣ为漏极-浮栅电容耦合因子。

2. **编程机制**：
   - 编程：沟道热电子注入（CHEI），Vwrite = 4.6 V，200 μs；
   - 擦除：碰撞电离热空穴注入（IHHI），Vwrite = 6–7.2 V，100 μs；
   - 可编程电流范围超过两个数量级（约0.4 nA至80 nA），在Vread ≈ 1 V时器件呈亚阈值指数特性。

3. **保持损失统计模型**：
   - 使用对数-对数线性拟合描述电流漂移：
     \[
     \log_{10}[I_i] = m \cdot \log_{10}[I_{P_i}] + q + \chi
     \]
     其中，m为斜率（漂移速率相关量），q为1 nA处的截距，χ = N(0, σ²)为零均值正态随机变量（表示器件间随机波动）；
   - m、q、σ均随编程后时间变化，通过10、30、60天的实测数据标定。

4. **权重映射方案**：
   - 有符号权重采用差分方案：正负权重分别映射到两个独立存储阵列，列电流相减得到有符号矩阵-向量乘结果；
   - 软件权重映射到单元电流的公式：
     \[
     I_{P_i} = \frac{|W_i|}{W_{\max}} (I_{\max} - I_{\min}) + I_{\min}
     \]
     其中Imin = 0.4 nA，Imax = 80 nA；
   - 输入激活量化至7位。

5. **BNR的实现方式**：
   - 使用校准数据集重新估计每个批归一化层的均值和方差参数，更新激活统计量，以补偿保持损失引起的分布偏移（遵循文献[18]的方法）。

6. **评估框架**：
   - 在硬件感知的推理仿真框架中集成校准后的保持损失模型，以蒙特卡洛方式模拟随机权重扰动。

## 六、主要结论与发现

1. **保持损失可分解为系统性+随机性两部分，且需要两种互补的缓解手段**：
   - 单独的VRC只补偿平均漂移；
   - 单独的BNR只补偿随机激活分布偏移；
   - 两者**联合使用为必要条件**才能显著恢复精度。

2. **60天后的精度恢复效果**：
   - VGG-10/CIFAR-10：联合方法（VRC+BNR）达到 **91.4% ± 0.3%**，相比参考93.7%仅损失约2.3个百分点（约2.4%相对偏差）；
   - WideResNet-28-10/CIFAR-100：联合方法达 **78.3% ± 0.5%**，相比参考82.1%仅损失约3.8个百分点（约4.6%相对偏差）；
   - 论文摘要表述为“恢复至基线的2–4%（误差范围内）”。

3. **仅BNR、仅VRC在60天时均严重退化**：
   - VGG-10：仅BNR为59.6% ± 1.3%（无VRC），远低于联合方案；
   - WRN-28-10：仅BNR为45.9% ± 2.0%。

4. **随机性随平均漂移增大而增大**：σ(V1n)与平均V1n漂移呈正比关系，说明器件间差异主导随机波动。

5. **联合缓解方案在60天尺度上精度波动小、分散度低**，为浮栅模拟存内计算的实际部署提供了可行路径。
