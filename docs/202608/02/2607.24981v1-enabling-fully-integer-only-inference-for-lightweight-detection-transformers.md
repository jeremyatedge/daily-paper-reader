## 摘要
视觉Transformer检测器现在在精度上接近CNN，但仍难以部署在NPU和微控制器上，因为关键组件（包括可变形注意力、特征融合和非线性激活函数）本质上与整数算术不兼容。现有的量化检测器要么保留Softmax、GELU和LayerNorm等算子，要么专注于重型骨干网络，使得轻量级检测Transformer缺乏端到端的整数实现。我们通过I-LW-DETR解决了这一空白，这是首个全整数轻量级DETR，其前向传播中的每个操作（包括Transformer非线性）都以整数算术执行。I-LW-DETR基于三个关键组件：一种保尺度分割卷积，为多尺度投影仪的每个分支分配独立的激活尺度；SD-ShiftGELU，一种符号依赖的GELU近似，保留逐元素行为同时避免精度下降；以及一种约束Shiftmax，维持稳定的Softmax归一化。实验结果表明，所提出的量化流水线在不同模型规模下 consistently 生成高效的纯整数模型。在所有模型规模下，所提出的流水线仅引入适度的精度下降，同时将模型大小减少约$3.6\times$，计算成本降低一个数量级以上。

## Abstract
Vision Transformer detectors now approach the accuracy of CNNs but remain difficult to deploy on NPUs and microcontrollers because key components, including deformable attention, feature fusion, and nonlinear activation functions, are not natively compatible with integer arithmetic. Existing quantized detectors either retain operators such as Softmax, GELU, and LayerNorm or focus on heavyweight backbones, leaving lightweight detection transformers without an end-to-end integer implementation. We address this gap with I-LW-DETR, the first fully integer-only lightweight DETR, in which every operation in the forward pass, including transformer nonlinearities, is executed in integer arithmetic. I-LW-DETR is built upon three key components: a scale-preserving split convolution that assigns independent activation scale to each branch of the multi-scale projector; SD-ShiftGELU, a sign-dependent GELU approximation that preserves element-wise behavior while avoiding the accuracy degradation; and a constrained Shiftmax that maintains stable Softmax normalization. Experimental results demonstrate that the proposed quantization pipeline consistently produces efficient fully integer-only models across different model scales. Across all model scales, the proposed pipeline incurs only a moderate accuracy degradation while reducing the model size by approximately $3.6\times$ and the computational cost by more than one order of magnitude.

## 2. 方法论

**核心思想：**
> 不是简单地对现有检测器套用通用量化流程，而是**重新设计架构与整数近似**，使整个网络完全在整数域中运行。部分操作本质上与整数硬件不兼容（如双线性插值、三角函数），需要通过架构重设计解决；其余挑战来自数值精度（如异构激活范围、异常值导致的精度崩塌），通过设计专用的整数近似算子解决。

**整体流程：**
1. 先构建**QR-LW-DETR**（quantization-ready LW-DETR）：一个量化就绪的浮点变体，作为量化前的浮点基线；
2. 再从QR-LW-DETR出发，通过PTQ或QAT生成最终的I-LW-DETR整数模型。

**关键技术细节：**

**(1) 量化就绪的架构改造（QR-LW-DETR）**

- **双线性插值→最近邻采样**：原LW-DETR解码器中的可变形注意力依赖双线性插值获取连续采样位置的像素值，涉及分数权重和浮点乘加运算。作者将其替换为**最近邻采样**，直接取最近的网格点特征，消除插值系数的浮点计算。
- **正弦位置编码→可学习投影模块**：两阶段检测中，编码器选出的参考框需经正弦编码转换为位置查询，涉及三角函数。作者改用**线性层组成的可学习投影模块**，与其余线性层共用同一套整数矩阵乘法流水线。

**(2) 线性算子整数化**

- 采用I-ViT的对称量化框架：权重用**逐通道（per-channel）** 对称量化，激活用**逐张量（per-tensor）** 对称量化，乘累加在整数域完成后统一缩放。

**(3) 保尺度分割卷积（Scale-Preserving Split Convolution）**

- **问题**：LW-DETR的projector接收来自ViT编码器不同阶段的多个特征图，这些特征图的激活范围差异很大。但在I-ViT框架下，所有拼接后的特征共享一个激活尺度，导致动态范围小的特征图量化分辨率被压缩。
- **解决方案**：将projector卷积改为**多分支独立卷积**，每个编码器输出分支保留独立的激活尺度。由于各分支尺度不同，累加前需统一缩放到公共输出尺度（取各分支校准尺度的最大值），该缩放作为固定仿射变换，用整数乘位移（dyadic multiply-and-shift）实现，保证全程整数运算。

**(4) 符号依赖ShiftGELU（SD-ShiftGELU）**

- **问题**：I-ViT的ShiftGELU通过向量级最大值减法 `I∆ = Ip − max(Ip)` 保证ShiftExp输入非正，但这引入元素间依赖。若某一元素是大的正值，它会将其他元素推向更负的区域，而ShiftExp在输入越负时相对误差越大（见原文Figure 3），导致GELU近似精度急剧下降。
- **解决方案**：利用Sigmoid的等价分解：
  - 当z≥0时：σ(z) = 1/(1+exp(−z))，exp输入为−z（非正）；
  - 当z<0时：σ(z) = exp(z)/(1+exp(z))，exp输入为z（也为负）。
  - 整数实现为 `I∆ = Ip − ReLU(Ip)`，对每个元素独立处理，消除全局最大值操作和元素间依赖，避免将激活推入ShiftExp的高误差区域。

**(5) 约束Shiftmax（Constrained Shiftmax）**

- **问题**：I-ViT Shiftmax用固定精度参数M（硬件精度M_hw=31）做整数Softmax归一化，但检测器中不同注意力层的指数累积和可能超出32位整数可表示范围，导致归一化因子精度崩塌甚至为零。
- **解决方案**：为每个Shiftmax块**校准一个分母移位参数sd**：
  - 在校准阶段统计每块的指数和S_sum，估计所需精度 `M_req = ⌈log2(S_sum)⌉`，加上安全裕度 `M_target = M_req + m_p`（m_p=4）；
  - 计算 `sd = max(M_target − M_hw, 0)`；
  - 利用**商-余数累加**（quotient-remainder accumulation）保持移位的精确性：`S_R = ΣQ_i + ⌊(Σr_i)/2^sd⌋ = ⌊S_sum/2^sd⌋`，避免逐个移位后求和带来的舍入损失；
  - 最终输出 `I_out,i = (I_exp,i · F) ≫ (31 − k_out + 1 + s_d)`，其中F = ⌊(2³¹−1)/S_R⌋。

**(6) 其他细节**
- LayerNorm采用整数平方根+牛顿迭代法，解码器中迭代次数从10增至20以改善稳定性。

## 6. 主要结论与发现

**1. 架构改造代价极小：**
- QR-LW-DETR相比原FP32 LW-DETR仅损失0.6–1.7 mAP（COCO），模型大小和计算量几乎不变。

**2. 全整数推理带来巨大效率收益：**
- PTQ后三种模型规模均实现：**模型大小压缩约3.6×**，**BOPs减少12.9–14.4×**（超过一个数量级）。

**3. QAT显著恢复精度：**
- QAT在保持效率不变的前提下恢复1.9–3.1 mAP（COCO）；最终相对FP32基线仅损失4.3–5.4 mAP。

**4. 模型容量越大，对量化越鲁棒：**
- Medium模型在QAT后保留最大比例的浮点精度（47.1 vs 50.8 mAP），这一趋势在COCO和VisDrone上均成立。

**5. I-ViT算子不能直接迁移到检测：**
- 组件消融显示：I-ViT ShiftGELU使检测精度崩至接近零（Tiny 0.0、Small 8.2、Medium 2.1 mAP），Shiftmax使Tiny降至6.3 mAP，projector量化使Medium损失约13 mAP。三个新组件逐步恢复性能：SD-ShiftGELU（+最大增量）、Constrained Shiftmax（尤其对Tiny关键）、Split Conv2d（对Small/Medium关键）。

**6. 在小目标密集场景（VisDrone）上更具挑战：**
- 精度下降显著大于COCO，尤其AP_S下降最大；QAT恢复后小目标精度仍偏低，表明最近邻采样可能削弱小目标的定位精度，是TODO方向。

**7. 与EIQ-DETR对比优势明显：**
- I-LW-DETR-Medium达到47.1 mAP（EIQ-DETR为44.1），同时模型小约1.4×、BOPs低约1.9×，且架构为轻量级。

## 7. 优点

**方法设计层面：**
- **首创性**：首个全整数轻量级DETR，补齐了该方向的空白。
- **“架构重设计+数值近似”双管齐下**：不仅解决“如何近似”的问题，还识别出“哪些操作本质不可量化、必须重新设计”（双线性插值→最近邻采样、正弦编码→可学习投影），方法高度系统化。
- **三个组件的设计均有明确的问题诊断支撑**：每个模块都来源于对失效模式的具体分析（ShiftGELU高误差区、Shiftmax溢出、projector尺度失衡），而非盲目修补。
- **SD-ShiftGELU的符号分解技巧优雅**：利用Sigmoid数学等价性消除全局依赖，每个元素独立处理，同时保证ShiftExp输入非正，理论上有清晰优势。
- **Constrained Shiftmax的商-余数累加**：避免逐个移位舍入，保持了数学上精确的移位和，兼顾数值稳定性与信息保真。

**实验层面：**
- 消融实验设计得非常系统：从“单独量化每个算子定位瓶颈”到“累积加入新组件量化贡献”，再到“每个新组件单独深挖”，层层递进、逻辑闭环。
- 同时评估PTQ和QAT，覆盖实际部署的两种主要路径。
- 在COCO之外增加VisDrone挑战场景，验证迁移性与泛化能力。
- 报告BOPs（比特操作数），比简单的FLOPs更能反映低精度推理的真实计算成本。
- 硬件兼容性讨论（与Ethos-U85对照）展示了从算法到硬件的落地思考。

## 8. 不足与局限

**实验覆盖与公平性：**
- 未做真实硬件部署测量：只有BOPs理论估计，没有实际NPU/微控制器上的延迟、吞吐量、能耗数据，结论的“部署效率”缺少直接实证。
- Table 4的对比不严格对等：不同方法用的架构、骨干、输入分辨率均不同，作者自己声明只能“contextual”地解读。
- 未与较新的FP16/混合精度基线比较，无法证明“全整数”始终优于“保留少量浮点算子”的折中方案。

**方法局限：**
- **最近邻采样可能损害小目标精度**：VisDrone实验中作者自己指出，双线性插值的替换可能降低小物体的定位精度，这是一个已知的精度-可量化性权衡。
- **量化范围仅验证8/8/16配置**：未探索更低比特（如4位、6位）下的表现，不能确认在4-bit边缘硬件上是否仍有效。
- 普适性有限：仅验证了LW-DETR这一种架构，其他轻量级DETR（如RT-DETR-Lite、D-FINE等）是否适用未知。

**其他遗憾：**
- 论文时间标注为2026年（arXiv:2607.24981v1），但未在文中说明与作者前期工作（如I-Segmenter）在方法继承上的细微差异，部分读者可能需要单独查阅前序工作才能完全理解SD-ShiftGELU的改进意义。
- 未报告QAT的收敛曲线或稳定性的详细分析，削弱了对“QAT恢复精度”这一核心结论的过程性支撑。
