## 摘要
非侵入式负载监测(NILM)系统通过单一的聚合计量表估算单个家用电器的能耗，而无需为每个设备配备单独的传感器。通过安装一个测量建筑物总用电量的计量表，NILM算法可以确定每个电器的运行状态。然而，传统的NILM系统使用计算密集型的优化算法来处理离线数据，限制了其在设备端部署的能力，而敏感的家庭数据必须在本地处理。本文提出了一种基于Tsetlin机(TM)的NILM框架，针对资源受限的微控制器(MCU)上的实时应用，实现了隐私保护的边缘部署。该问题被重新表述为一个分类任务，所提出的方法在REDD数据集上，对于两种电器分类实现了90%的平均精确率和96%的平均召回率，对于四种电器实现了77%的精确率和80%的召回率。训练后的模型仅占用18KB的闪存，在ESP32上的推理延迟为0.43毫秒，展示了其在MCU上用于嵌入式NILM应用的适用性。

## Abstract
Non-Intrusive Load Monitoring (NILM) systems estimate individual appliance energy consumption from a single aggregate meter, without requiring separate sensors for each device. By installing a single meter that measures a building's total electricity consumption, NILM algorithms can determine the active status of each appliance. However, traditional NILM systems use computationally intensive optimization algorithms to process offline data, limiting their capability for on-device deployment, where sensitive household data must be processed locally. This paper proposes a Tsetlin Machine (TM)-based NILM framework, targeting real-time applications on resource-constrained microcontrollers (MCUs), enabling privacy-preserving edge deployment. The problem is reformulated as a classification task, and the proposed approach achieves an average precision of 90% and recall of 96% for two-appliance classification, and 77% precision and 80% recall for four appliances on the REDD dataset. The trained model occupies only 18 KB of flash memory and achieves an inference latency of 0.43 ms on an ESP32, demonstrating its suitability for embedded NILM applications on MCUs.

## 1. 论文的核心问题与整体含义（研究动机和背景）

非侵入式负载监测（NILM）的目标是仅通过一个安装在建筑总电表处的单一传感器，从聚合功耗信号中分解出各个家用电器的独立能耗，从而避免为每个设备单独安装传感器所带来的高昂成本与安装复杂度。然而，传统NILM方法面临两大瓶颈：

- **计算瓶颈**：无论是基于模型的方法（如隐马尔可夫模型、混合整数线性规划），还是基于机器学习/深度学习的方法，都依赖计算密集型的优化算法，通常需要离线处理完整数据段，难以满足实时监测需求。
- **隐私瓶颈**：若将家庭用电数据上传至云端处理，会带来敏感数据泄露风险，因此需要支持本地处理的边缘部署方案。

本文的核心动机是：利用 Tsetlin Machine（TM）——一种轻量级、基于布尔逻辑运算的机器学习模型——在资源受限的微控制器（MCU）上实现近实时的 NILM 系统，从而在本地完成数据处理，兼顾**实时性**与**隐私保护**。

## 2. 论文提出的方法论

论文的核心思想是将 NILM 问题重构为一个**分类任务**：先检测聚合信号中的电器开关事件，再将每个完整活动窗口分类到对应的电器类别。系统采用事件驱动架构，仅在检测到功率跃变时触发处理，显著降低了 MCU 上的计算开销。

整个系统由四个模块组成：

1. **边缘检测（Edge Detection）**  
   采用 Hart [1] 提出的稳态检测思想，仅在功率达到新稳态时判定为一次有效跃变，从而滤除传感器噪声和瞬时尖峰。该算法被重新实现为面向 MCU 实时流数据的版本。

2. **事件配对（Event Pairing）**  
   将上升沿（电器开启）与后续下降沿（电器关闭）配对，形成完整活动窗口。配对策略包括：
   - 局部搜索：在最近上升沿列表中匹配功率变化最接近的下落沿；
   - 全局优化：在局部策略基础上引入全局动态规划，定义候选对的功率误差 \(e_{ij} = |\Delta P_i^+ + \Delta P_j^-|\)，允许容差 \(\tau_{ij} = \max(100, 0.25|\Delta P_j^-|)\)，并以评分 \(s_{ij} = 1 - e_{ij}/\tau_{ij}\) 最大化总匹配分数，确保每个边缘至多使用一次。

3. **特征提取（Feature Extraction）**  
   对每个配对后的活动窗口提取 **21 维特征**，涵盖四类信息：
   - 过渡特征（变化幅值、持续时间等）；
   - 稳态统计（均值、标准差、极值、功率范围）;
   - 内部动态（逐样本差分统计、活跃状态占比、内部子循环数）；
   - 能量与上下文（事件能量估算、事件前后平均功率差）。

4. **TM 分类（Tsetlin Machine Classification）**  
   - **布尔化**：由于 TM 仅接受布尔输入，各浮点特征先归一化至 [0,1]，再缩放至 [0,255] 并转为 8 位整数，最后按位分解为布尔向量。
   - **离线训练、在线推理**：TM 模型在主机上离线训练，通过 Protobuf 序列化后部署至 MCU。部署时仅保留活跃 Tsetlin 自动机的索引，剔除冗余状态信息，大幅压缩内存占用。
   - **推理**：TM 推理仅涉及简单布尔逻辑运算，无浮点乘法和矩阵运算，非常适合 MCU 环境。

## 3. 实验设计

**数据集**：使用 REDD 公共数据集（6 栋住宅），经 NILMTK 工具包预处理。  
**划分方式**：使用建筑 1、2、4、5、6 作为训练集，建筑 3 作为测试集——理由是建筑 3 包含研究中涉及的所有电器类型。  
**超参数优化**：使用 Optuna 框架进行超参数搜索。最终配置为：286 个 clause、196 个 TA 状态、8 位特征编码、阈值 T=20、特异性 s=6.0、训练 10 个 epoch。

**实验组别**：
1. **二分类实验**：区分冰箱（Fridge）与微波炉（Microwave）；
2. **多分类实验**：区分冰箱、微波炉、洗碗机、电炉四种电器；
3. **资源消耗评估**：测量模型的 Flash/SRAM 占用与推理延迟。

**对比情况**：论文**未与其他 NILM 方法（如 FHMM、LSTM、SVM 等）进行定量对比**，仅报告了所提方法自身的性能指标。

**主要实验结果**：
- 二分类：冰箱 Precision 0.99 / Recall 0.97，微波炉 Precision 0.80 / Recall 0.95；整体平均 Precision 90%、Recall 96%。
- 多分类：冰箱 P=0.84 / R=0.94，微波炉 P=0.75 / R=0.95，洗碗机 P=0.10 / R=0.08，电炉 P=0.50 / R=0.15。
