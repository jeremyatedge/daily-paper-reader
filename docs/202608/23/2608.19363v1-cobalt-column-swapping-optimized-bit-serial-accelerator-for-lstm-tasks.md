## 摘要
长短期记忆（LSTM）网络持续被广泛部署于边缘设备上的实时序列任务，但其计算需求对资源受限硬件上的部署构成挑战。本工作提出COBALT，一种基于标准循环矩阵-向量乘法（MVM）的矩阵（输入）-向量（权重）重构，并采用偏移二进制编码的位串行压缩LSTM加速器。一种新颖的列交换方案在成对生成部分积时于位级操作，系统性地暴露输出行间的冗余，从而减少部分积生成器和选择器的数量。该冗余进一步通过一个轻量级校正单元被利用，该单元直接从其配对行推导出某行的输出。此外，对于分块循环MVM，重新定位每个子MVM的移位累加和校正单元进一步降低了资源使用。压缩网络在TIMIT和LibriSpeech-100h基准上实现了高达93.6%的权重压缩，同时保持准确性。在现场可编程门阵列上，COBALT相对于最先进的LSTM加速器实现了优越的整体效率。

## Abstract
Long Short-Term Memory (LSTM) networks continue to be widely deployed for real-time sequential tasks on edge devices, yet their computational demands challenge deployment on resource-constrained hardware. This work introduces COBALT, a bit-serial compressed LSTM accelerator built on a matrix (input)-vector (weight) reformulation of the standard circulant matrix-vector multiplication (MVM) with offset-binary coding. A novel column-swapping scheme operates on partial products at the bit level when generated in pairs, systematically exposing redundancy across output rows to reduce the number of PP generators and selectors. This redundancy is further exploited using a lightweight correction unit that derives a row's output directly from its paired row. Additionally, for block-circulant MVMs, relocating the shift-accumulate and correction units of each sub-MVM further reduces resource usage. The compressed network achieves weight compression of up to 93.6% while maintaining accuracy on the TIMIT and LibriSpeech-100h benchmarks. On a field-programmable gate array, COBALT achieves superior overall efficiency relative to state-of-the-art LSTM accelerators.

## 2. 方法论：核心思想、关键技术细节

### 2.1 整体框架
- COBALT将LSTM的8个MVM压缩为两组循环输入矩阵与权重向量的乘加（公式8），并采用**偏移二进制编码（OBC）+分布式算术（DA）** 进行位串行计算。
- 与已有工作（权重循环矩阵）不同，COBALT采用**输入循环矩阵**：因为循环MVM的PP生成与选择可解耦，且输入数量（2N）远小于权重数量（8N），可显著减少PPG/PPS数量。

### 2.2 关键技术：列交换方案（Column Swapping）
- **核心思想**：对循环MVM的部分积矩阵Uʷ(k)进行一次性或多次列交换（算法1），将原始2×2棋盘格划分下的PP重配对为沿对角线对称/反对称的结构，从而暴露行间的PP冗余。
- **效果**：N=4时，仅需2个PPG（生成(±u₁±u₃)/2和(±u₂±u₄)/2对）取代4个，PPS数量减半；对N=8，需两步交换（在N/4、3N/4处进行），仅需4个PPG。
- 一般化：任意N×N循环MVM可通过log₂N−1步交换，将PPS数量从(N/2)²降至2(N/4)²，减少37.5%。

### 2.3 轻量校正单元（Correction Buffer, CB）
- **行对冗余规律**：配对行（如Row 1 与 Row 3）的PP和Saᵤ₃[k]相对于Row 1的Saᵤ₁[k]存在三种关系：相等、精确取反、或需校正。
- **公式**：Su₃[k] = Su₁[k] − Δ₃[k]，其中校正因子Δ₃[k]∈{0, (u₁−u₃), (u₂−u₄)}，由EQ/CS控制信号选择（来自权重位异或逻辑）。
- **实现**：CB保留移位反馈结构（CB₃[k] = Δ₃[k] + ½CB₃[k−1]），但其输入完全来自校正因子，**无需专用加法器**；最终输出 v₃ = SA₁[B−1] − CB₃[B−1]，复用CB的加法器完成最终减法。
- **扩展性**：N=8时，将4个PP对分组为(P=A+B, Q=C+D)，每组独立EQ/CS，Δ₅=Δ₅(P)+Δ₅(Q)，通过三操作数合并加法器归入单一CB。行对的4个基本差分 (uᵢ−uᵢ₊₄) 被所有行对复用，无需额外减法器。

### 2.4 分块循环MVM优化
- 对块循环MVM（N=pq），旋转矩阵Ψ破坏了子MVM的棋盘格结构；通过在PP矩阵**边缘**（而非中点）发起列交换，使方案适用于所有子MVM。
- 时间复用：p个子MVM共享q/2个SA和q/2个CB（而非pq个独立单元），大幅减少加法器和寄存器。
- 整体硬件复杂度汇总：4pα+6pα²+q个加法器；6pα²+24α²+24α+q+pq²个2-1多路选择器；24pα/B个XOR/XNOR门；12α+q个寄存器（α=q/4）。

### 2.5 训练策略
- 采用**ADMM（量化权重）+STE（量化激活）** 的定点FxP8训练流程；先训练FlP32基线模型，再用循环矩阵结构重训练（curriculum warm-start：每个块大小q从前一个q的收敛权重起步）。
- 激活函数（σ/tanh）用组合逻辑+LUT近似实现，前向用分段线性近似，反向用原始非线性函数计算梯度。

## 6. 主要结论与发现

- **精度-压缩权衡**：FxP8循环模型在TIMIT上PER从23.54%（FlP32基线）降至21.64%（ΔPER −1.90%），压缩率93.64%；LibriSpeech同样改善（WER从12.84%降至11.45%，ΔWER −1.39%）。块循环q-sweep显示精度成本随q增大单调递减，并在q=N处收敛到全循环模型；**分块循环结构自身的正则化效应是精度-压缩权衡的主导因素，而非数据集规模**。
- **硬件效率**：COBALT在N=256、q=4的FPGA实测中，每样本能耗0.141 nJ，较DA 1c改善81.2%、较DA 2b改善84.5%，资源利用率全面最低。
- **综合对比**：COBALT的ENS（8.12K slices）为所有对比设计中最低（约为Spartus的1/5）；EPE为0.56，较最佳先前基线Spartus改善2.43×。在保持可比精度（PER 20.3–22.2%）的同时，以零DSP/零BRAM实现优于SOTA的整体效率。
- **硬件效率结论**：COBALT的功耗极大降低（6.3×低于Spartus）超越了其吞吐劣势（约为Spartus的一半），从而在能耗效率上占据优势——这一权衡源于其纯LUT/FF的乘加器路径设计。

## 7. 优点与亮点

- **理论创新性**：首次将循环/分块循环MVM重构为“输入矩阵–权重向量”形式，从根本上减少LSTM设计中PPG数量（4×削减），打破了已有设计按权重数量扩展的瓶颈。
- **硬件优化完备性**：从PPG/PPS优化（列交换）到行间冗余利用（CB校正单元），再到块循环结构的SA/CB重定位，形成了从位级到架构级的多层优化链条，逻辑连贯。
- **可扩展性**：算法1适用于任意N=2^m的循环MVM；N=8的通用推广（分组P/Q校正）可自然扩展到更大规模，鲁棒性好。
- **零DSP/零BRAM的设计**：仅用LUT/FF实现全部计算，特别适配资源受限或DSP/BRAM吃紧的FPGA平台，也间接降低了动态功耗。
- **实验设计较严谨**：双数据集验证、匹配基线、q-扫描曲线、跨平台ENS归一化、对测量方法差异的透明说明，均体现了较高的方法论水准。
- **训练策略的实用性**：ADMM+STE组合、curriculum warm-start和循环初始化保持方差等技巧有实际参考价值。
