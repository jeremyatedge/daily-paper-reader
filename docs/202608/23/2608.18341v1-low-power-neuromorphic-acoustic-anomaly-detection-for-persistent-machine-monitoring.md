## 摘要
持续声学监控可以在无需物理接触的情况下检测机器故障，但始终在线的推理受到功耗、延迟和部署复杂性的限制。我们展示了在Intel Loihi 2神经形态处理器上，在干净和噪声条件下基于自编码器的声学异常检测。对数梅尔特征在片外计算；归一化、自编码器推理、L1重建评分和阈值判定均在片上运行。在干净的、与麦克风位置无关的ToyADMOS ToyCar基准测试中，片上模型在最大假阳性率为0.1时实现了0.9959的AUC和0.9785的标准化pAUC。在DCASE 2026任务2 ToyCar噪声基准测试中，该模型实现了源域AUC 0.7990、目标域AUC 0.6466和pAUC 0.6426，超过了报告的基线指标。在16芯片Loihi 2 VPX系统上的功耗分析显示，实时吞吐量下每个样本的动态能量为0.0406–0.0426 mJ，比CPU和GPU低两个数量级。这些结果支持神经形态声学异常检测作为低功耗、持续机器监控的实用候选方案。

## Abstract
Persistent acoustic monitoring can detect machine faults without physical contact, but always-on inference is constrained by power, latency, and deployment complexity. We demonstrate autoencoder-based acoustic anomaly detection on an Intel Loihi 2 neuromorphic processor under clean and noisy conditions. Log-mel features are computed off chip; normalization, autoencoder inference, L1 reconstruction scoring, and thresholding run on chip. In a clean, microphone-position-invariant ToyADMOS ToyCar benchmark, the on-chip model achieves 0.9959 AUC and 0.9785 standardized pAUC at maximum false-positive rate 0.1. In the DCASE 2026 Task 2 ToyCar noisy benchmark, the model achieves source AUC 0.7990, target AUC 0.6466, and pAUC 0.6426, exceeding reported baseline metrics. Power profiling on a 16-chip Loihi 2 VPX system shows real-time throughput with 0.0406$\unicode{x2013}$0.0426 mJ dynamic energy per sample, two orders of magnitude lower than both a CPU and GPU. These results support neuromorphic acoustic anomaly detection as a practical candidate for low-power, persistent machine monitoring.

## 1. 核心问题与研究动机

- **背景**：持续机器监控（persistent machine monitoring）需要设备长期处于“始终在线”状态，以便及时发现罕见故障。声学监控因非接触、能感知旋转/振动部件频谱变化而具有吸引力。
- **痛点**：传统“始终在线”推理在功耗、延迟和部署复杂度上受限，难以满足低功耗持久监测需求。
- **解决方案方向**：神经形态处理器（如 Intel Loihi 2）通过分布式状态、稀疏通信和低精度事件驱动计算，为低功耗持续推理提供了新架构。
- **本文目标**：在 Loihi 2 上实现严格意义上的**单类（one-class）声学异常检测**（仅用正常声音训练），并在干净与噪声条件下评估检测精度、延迟、功耗、能量等指标。

## 2. 方法论

- **总体流程**：  
  对数梅尔（log-mel）特征在片外提取 → 固定点归一化、自编码器推理、L1 重建评分、阈值判决均在 Loihi 2 片上执行。
- **特征表示**：
  - 干净数据（ToyADMOS，48 kHz）：用 2048 点 FFT、Hann 窗、hop 512，400 个 mel 频带，取中间 93 帧（约 1 秒）并时间平均为 400 维向量。
  - 噪声数据（DCASE 2026，16 kHz）：用 1024 点 FFT、hop 512，416-bin mel 滤波器组，取中心 1 秒段平均为 416 维向量。
- **自编码器结构**：
  - `x → 256 → 128 → 64 → b → 64 → 128 → 256 → x̂`

- **量化与片上计算**：
  - 权重为 8-bit 有符号整数，累加器/偏置/激活限制在 24-bit 有符号范围。

- **训练**：

## 6. 主要结论与发现

- 在干净 ToyADMOS ToyCar 数据上，Loihi 2 片上模型达到 **AUC 0.9959、pAUC 0.9785**，说明神经形态自编码器能有效区分正常与异常声音，且对麦克风位置变化不敏感。
- 在噪声 DCASE 2026 ToyCar 数据上，**源域 AUC 0.7990、目标域 AUC 0.6466、pAUC 0.6426**，**全部超过 DCASE 基线**（0.7728 / 0.5317 / 0.5825），且仅用近麦克风、无独立噪声参考。

- 静态功耗在 VPX 16 芯片系统中占主导，但模型仅用 74 核，留有大量片上资源。
- 总体表明：神经形态声学异常检测是低功耗持久机器监控的实用候选方案。

## 7. 优点

- **严格的单类异常检测设置**：训练仅用正常样本，异常只参与评估，符合真实工业场景。
- **全流程片上推理**：归一化、自编码器、L1 评分、阈值判决都在 Loihi 2 上完成，展示了神经形态芯片的“端到端”决策能力。
- **量化方法可行**：8-bit 权重 + 24-bit 累加，并通过位右移实现缩放，在保持高 AUC 的同时适应神经形态硬件。

- **测量细致**：区分总能量与动态能量，报告了内存占用、活动事件数、核心数等，便于评估部署可行性。
- **提供单芯片功耗估算**：基于 Oheo Gulch 静态功耗数据推导 VPX 静态功耗，并给出单芯片投影。
