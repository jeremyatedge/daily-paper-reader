## 摘要
状态空间模型（SSM），如Mamba和Mamba-2，实现了线性时间的自回归推理，这使得它们在对延迟敏感和资源受限的部署中具有吸引力。然而，它们的大型输入和输出投影层带来了二次方的权重内存和片外带宽成本，这成为FPGA实际部署的瓶颈，在序列长度为1,024及以上时，每token运行时间中超过60%被其占用。现有加速器通过量化或激活稀疏性来减少这种开销，但没有一个将投影秩作为显式的硬件设计变量，留下了系统性的精度-吞吐量权衡未被探索。我们提出了LowRank-SSM，一个填补这一空白的软硬件协同设计框架。在软件方面，我们通过训练后截断SVD分解输入和输出投影权重，并引入一种贪婪的带状秩分配算法，该算法搜索每个频带的秩向量，在满足用户指定精度约束的同时最小化权重存储。在硬件方面，我们将得到的因子化投影映射到FPGA上的全流水线加速器，该加速器具有双路径投影（低秩路径和全秩路径）、融合选择性扫描单元，以及五个独立的AXI主接口束，可在无总线竞争的情况下饱和DDR4带宽。逐频带运行时秩掩码使得所有64层能够以混合秩执行，且零架构开销。在Xilinx Versal VC1902上，在400 MHz频率下，部署的混合秩INT8设计实现了7.89 tokens/s的吞吐量，在可比功率和精度下，相对于最先进技术，吞吐量提升了${2.19\times}$，能效提升了${2.03\times}$。

## Abstract
State Space Models(SSMs) such as Mamba and Mamba-2 achieve linear-time autoregressive inference, making them attractive for latency-sensitive and resource-constrained deployment. Yet their large input and output projection layers impose quadratic weight memory and off-chip bandwidth costs that bottleneck practical FPGA deployment, accounting for over 60% per-token runtime at sequence lengths of 1,024 and beyond. Existing accelerators reduce this overhead through quantization or activation sparsity, but none treat projection rank as an explicit hardware design variable, leaving a systematic accuracy-throughput trade-off unexplored.   We present LowRank-SSM, a hardware-software co-design framework that closes this gap. On the software side, we decompose the input and output projection weights via post-training truncated SVD and introduce a greedy bandwise rank-allocation algorithm that searches for the per-band rank vector that minimizes weight storage while respecting a user-specified accuracy constraint. On the hardware side, we map the resulting factored projections onto a fully-pipelined accelerator on an FPGA, featuring a dual-path projection(low-rank path and full-rank path), a fused selective-scan unit, and five independent AXI master bundles that saturate DDR4 bandwidth without bus contention. A per-band runtime rank mask enables mixed-rank execution across all 64 layers with zero architectural overhead. On Xilinx Versal VC1902 at 400 MHz, the deployed mixed-rank INT8 design achieves 7.89~tokens/s, representing a ${2.19\times}$ throughput improvement and ${2.03\times}$ energy-efficiency improvement over SOTA at comparable power and accuracy.

- **研究背景**：Mamba及其后续版本Mamba-2等选择性状态空间模型（SSM），凭借线性时间自回归推理和固定大小循环状态，成为Transformer在延迟敏感和资源受限场景下的替代方案。
- **核心问题**：尽管SSM的递归计算是高效的，但Mamba块中**输入/输出投影层的权重矩阵规模庞大**，构成实际部署瓶颈。如图1所示，在序列长度为1024及以上时，in_proj和out_proj合计占用**超过60%的每token运行时**，而SSM扫描本身仅占约24%。这本质上是**内存带宽瓶颈**（需从DDR逐token读取完整权重矩阵），而非计算瓶颈。

## 2. 方法论

### 2.1 核心思想

将输入输出投影权重矩阵W ∈ R^{m×n}用两个低秩因子逼近：W ≈ B_r · A_r，其中A_r ∈ R^{r×n}，B_r ∈ R^{m×r}。权重存储从m·n降至r(m+n)。当r < mn/(m+n)时，分解即有存储收益。

### 2.2 操作数选择

- **输入投影**：将token映射为五个操作数X、Z、Δ、B、C。其中**X是最大操作数**（占64%投影输出），通过后续深度卷积和SSM扫描，递归过程可部分吸收误差，因此**仅对W_X子矩阵做低秩分解**。
- **Z操作数**直接参与输出门控，误差会被放大，必须保持满秩；B、C、Δ影响状态动态，误差会随序列累积，且维度较小，也保持满秩。
- **输出投影**：out_proj ∈ R^{D×dinner}被整体分解，因其无状态反馈机制来吸收误差。

### 2.3 敏感性度量

定义三种灵敏度指标，在2048个WikiText-2 token校准集上评估：

- **Frobenius误差（E_F）**：矩阵级近似质量
- **谱误差（E_S）**：算子范数，更紧的逐token输出扰动上界
- **激活重建误差（E_A）**：在实际激活分布上度量输出保真度，最具判别力

采用**8层频带分组**（G=8），在分组粒度与搜索维度间取平衡。关键发现：**带8（第56~63层）在所有秩下误差最高，而前6个频带压缩性更好**——存在显著的层位置不对称性。

### 2.4 贪心带状秩分配算法（Algorithm 1）

- 所有频带从最大秩r₀=2560（满秩等价）开始
- 初始化：每个频带先降为其盈亏平衡秩
- 迭代：评估将所有非最小秩频带降低一档后的ΔPPL，接受预算内最小的那个
- 终止：当无候选满足预算Δmax时停止
- 实证发现：**带6/8连续被选中压缩**（平滑误差面允许长压缩路径），而带8/8单步就产生+1.21 PPL被立即拒绝，算法自然发现非对称性
- 最终配置：Δmax=3 PPL时，整体权重存储减少**20%**

### 2.5 硬件架构

- **整体架构**：单硬件内核顺序迭代64层，数据流调度最大化流水线重叠；流式FIFO背压通信
- **内存接口**：**5个独立AXI主端口**——token I/O、低秩权重、其余权重低/高半部分、量化缩放因子，饱和DDR4带宽
- **双路径投影单元**：低秩路径（两阶段GEMM：Stage 1 r×D，Stage 2 d_inner×r，中间瓶颈向量z保存在片上LUTRAM）+ 非低秩路径（生成Z、Δ、B、C，双GEMM引擎并行，DEMUX分流）；VRank掩码（每层1bit）实现混合秩切换
- **量化GEMM单元**：INT8权重、逐行分组（g=128）缩放，每处理通道2×DSP（1个反量化、1个MAC）
- **融合选择扫描单元**：将离散化（softplus）、状态更新、输出累积、D残差与Z门控合并为单流水线通道；消除3个中间FIFO；分层状态流式存储在DDR中，零拷贝反馈路径

## 6. 主要结论与发现

1. **投影层是真正的瓶颈**：in_proj和out_proj在长序列下占每token运行时的60%以上，SSM扫描本身仅占约24%——内存带宽而非计算是瓶颈。
2. **秩可作为一个独立且有效的硬件设计变量**：通过按频带贪心分配秩，Mamba2-2.7B可减少20%权重存储且ΔPPL < 3。
3. **秩降低与量化近似正交**：Δ=1低秩+INT8的组合成本（−1.0 pp）与单独成本之和一致；INT4也近似可加（预测−1.8 pp vs 实测−2.2 pp）。
4. **核心操作点**：Δ=1 LowRank+INT8在精度上与LightMamba INT4相当（56.4% vs 56.3%平均准确率），但LAMBADA表现显著更好（4.47 vs 6.48 PPL，69.2% vs 57.3%准确率）——表明**秩降低提供量化无法提供的结构性带宽节省，而INT8保住了激进量化所牺牲的生成质量**。
5. **硬件结果**：在Versal VC1902/400MHz上，64层混合秩INT8设计达7.89 tok/s，较LightMamba提升2.19×吞吐、2.03×能效，功耗几乎相同（27.4W vs 25.4W）。130M模型对比FastMamba提升27.8×/9.8×。
6. **层位置不对称性**：早期层和部分中层更可压缩；最深几层对秩降低高度敏感，揭示了非均匀秩分配的必要性。

## 7. 优点

- **问题定位精准**：通过运行时剖析数据定量指出投影层才是SSM部署的真正瓶颈，纠正了以往集中于优化扫描计算的思路偏向。
- **真正实现“软硬件协同”**：不仅是算法压缩+硬件实现的拼装，而是从权重分解到硬件数据通路（双路径、片上瓶颈向量缓存、混合秩掩码）的一体化设计——低秩分解的带宽收益在硬件层面被真正兑现。
- **方法简单有效**：训练后截断SVD+贪心搜索避免了昂贵的微调，可移植性强。
- **工程完整性高**：五个AXI主端口、融合扫描流水线、流式状态管理等细节使设计可实际部署并达到接近DDR带宽饱和。
- **消融实验设计清晰**：通过低秩-only、量化-only、组合三组实验验证了正交性，理论上的“近可加性”给出了令人信服的机理解释。

## 9. 结论总结

LowRank-SSM是首个将投影矩阵的**秩**作为显式硬件设计变量的SSM加速框架。软件端的截断SVD+贪心频带秩分配与硬件端的双路径投影数据通路、融合扫描单元和5端口AXI内存架构深度耦合，在Versal VC1902上以INT8精度实现了2.19×的吞吐提升和2.03×的能效提升，同时保持与SOTA相当的精度。这一工作为SSM的高效硬件部署提供了“结构性压缩+架构协同”的新范式，也展示了秩降低与量化作为两个近似正交的压缩维度的潜力与边界。
