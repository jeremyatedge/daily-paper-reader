## 摘要
视触觉传感器通过测量表面梯度重建密集接触几何形状，但基于主机的处理会增加功耗，并引入数据传输延迟和可变调度延迟，限制了机器人系统的感知和响应速度。为解决这些限制，我们实现了一种近传感器计算框架，其中包括一个作为全流式硬件管线的谱泊松求解器。计算核心逻辑的估计功耗为347毫瓦，且无需数据相关分支或迭代收敛即可实现高吞吐量，从而提供确定性延迟。该管线以166 MHz运行时，在接收到第一个输入像素后35,107个周期内产生每个128x128帧的首个深度值，对应0.211毫秒的固定延迟。在15种接触几何形状中，重建深度与双精度参考值的差异为峰值接触深度的0.17%。基于这些重建的片上决策在28.3±4.9毫秒内完成机器人保护性反射回路，而使用相同执行器的等效主机回路则需要169.9±27.8毫秒。这些结果表明，近传感器重建能够在适合快速机器人接触响应的时间尺度上，提供准确、节能且确定性的触觉几何信息。

## Abstract
Visuotactile sensors reconstruct dense contact geometry from measured surface gradients, but host-based processing increases power consumption and introduces data-transfer delays and variable scheduling latency, limiting the sensing and response speed of robotic systems. To address these limitations, we implement a near-sensor computing framework that includes a spectral Poisson solver as a fully streaming hardware pipeline. The computational core logic has an estimated power consumption of 347 mW and achieves high throughput without data-dependent branching or iterative convergence, thereby providing deterministic latency. Operating at 166 MHz, the pipeline produces the first depth value of each 128x128 frame 35,107 cycles after receiving the first input pixel, corresponding to a fixed latency of 0.211 ms. Across 15 contact geometries, the reconstructed depths differ from a double-precision reference by 0.17 % of the peak contact depth. On-chip decisions based on these reconstructions close a robot protective reflex loop in 28.3 +/- 4.9 ms, compared with 169.9 +/- 27.8 ms for an equivalent host-based loop using the same actuator. These results demonstrate that near-sensor reconstruction can provide accurate, energy-efficient, and deterministic tactile geometry on timescales suitable for rapid robotic contact responses.

## 1. 核心问题与整体含义（研究动机和背景）

- 视触觉传感器（如 GelSight 类）通过成像软弹性体的形变，利用光度立体视觉和泊松积分重建密集 3D 接触几何，可支持接触力估计、滑移检测、物体位姿估计等丰富下游任务。
- 当前主要瓶颈在于 **3D 重建速度**：从密集梯度场求解泊松方程计算量大，在通用 CPU 上通常需要数十毫秒，且受操作系统调度和主机数据传输影响，延迟存在明显抖动，严重限制了机器人的控制带宽与快速闭环响应能力。
- 已有两类缓解方案均有根本性权衡：
  - 简化表示（如直接预测法向或任务变量）：可达到 100–200 Hz，但缺乏可跨任务复用的统一 3D 几何描述；
  - 事件触觉传感：可达 kHz 级时间分辨率，但信号稀疏、仅编码时间变化，无法进行密集几何重建。
- 近传感/传感内计算虽已在电容式、压阻式触觉中用于滤波、特征提取等简单操作，但将其扩展至视触觉感知的核心难点在于：**需要在传感器接口处实时求解泊松方程**，而现有硬件 PDE 加速器多采用迭代求解器（多重网格、共轭梯度等），其收敛时间依赖输入场和容差，延迟不确定。
- 本文的核心意图：**将谱泊松求解器映射为全流式硬件流水线，在传感器节点完成从感知到决策的本地闭环**，实现确定性、低延迟、低功耗的密集触觉重建与响应，类比生物体的脊髓保护性反射通路。

## 2. 方法论：核心思想与关键技术

**核心思想**：将基于谱方法的泊松求解器实现为完全流式（fully streaming）的硬件流水线，替代传统主机端软件求解或迭代式硬件加速器。由于执行路径固定、无数据依赖分支，延迟由构造保证确定。

**关键技术细节**：

- **谱求解方案**：二维泊松方程 \\(\nabla^2 z = \nabla \cdot g\\) 在齐次 Dirichlet 边界条件下，通过离散正弦变换（DST）对角化离散拉普拉斯算子，将问题转化为谱域的逐元素除法：
  - \\(\hat{z}_{kl} = \hat{f}_{kl} / (\lambda_k + \lambda_l)\\)
  - 深度图由逆二维 DST 恢复；二维 DST 按可分离方式分解为行、列两次一维变换。
- **流式硬件架构**（在 Xilinx Zynq UltraScale+ XCZU7EV 上实现，时钟 166 MHz）：
  - 像素按光栅扫描顺序进入，无整帧输入缓冲；
  - 光度立体核心：将原始 RGB 像素流转换为逐像素表面梯度；
  - 泊松核心：梯度差分 → 前向 DST → 谱域逐点除法 → 逆 DST；
  - 一维 DST 采用流水线 FFT 核心加输入重排和相位校正实现；
  - 行列两次变换之间通过整帧矩阵转置连接；所有运算采用 **24 位有符号定点数**。
- **确定性延迟**：流水线无迭代回路，每个 128×128 帧的延迟固定为 35,107 个时钟周期（0.211 ms），不受接触几何形状影响；吞吐量受像素时钟限制，理论可达 10,133 fps。
- **感知-决策片上闭环**：在可编程逻辑中实现阈值比较器，深度值流出流水线时逐点评估，超过阈值即在一个时钟周期内直接触发 GPIO，驱动伺服电机，全程无主机参与。

## 6. 主要结论与发现

- 近传感器谱泊松求解流水线在 166 MHz 下实现**固定 0.211 ms 重建延迟**，且逐帧零抖动；
- 重建精度优异：15 种接触几何下深度误差平均仅为峰值深度的 **0.17%**，视觉上与双精度参考无法区分；
- 功耗远低于主机方案：FPGA 逻辑 347 mW，45 nm ASIC 估计 324 mW；
- 片上闭环保护性反射：接触-运动延迟 **28.3 ± 4.9 ms**，比等效主机回路（169.9 ± 27.8 ms）快约 6 倍，且低于人类伤害性退缩反射的文献范围（65–137 ms）；
- 延迟随网格尺寸呈 O(N²) 缩放，资源（DSP/LUT）仅随尺寸温和增长，存储是主要限制因素。

## 7. 优点

- **确定性延迟的构造性保障**：全流式、无迭代、无数据依赖分支，优于依赖收敛条件的迭代求解器架构；
- **软硬件协同优化**：24 位定点数通过系统字长扫描确定，在精度与资源间取得良好平衡；
- **系统级创新**：首次将“感知-重建-决策”全链路在传感器节点本地闭环，类比生物脊髓反射，概念新颖且具有示范意义；
- **全面的量化验证**：从延迟分布、精度、资源、功耗到物理实验，证据链完整；
- **与相关工作形成互补**：与事件触觉传感、迭代式硬件加速器等方法的关系和差异阐述清晰。

## 8. 不足与局限

- **网格尺寸受限**：部署最大为 256×256，受片上存储（转置缓冲）限制，更大分辨率需外部存储器支持；
- **功耗评估边界不一致**：FPGA 功耗为仿真估计（非实测），且与对比平台（CPU/GPU）的测量边界不同，公平性有限；
- **软件基线计时条件**：CPU/GPU 基线仅包含泊松重建计算（输入数据和分母预计算），且未包含图像采集与传输开销，实际系统延迟可能更大——但这反而强化了本文方案的结论；
- **流水线尚未达到相机极限速率**：虽然流水线吞吐可达 10,000+ fps，但传感器最高 400 fps，实际系统受传感器限制；
- **反射实验时序分辨率受限**：高速相机以 480 fps（2.083 ms 帧间隔）记录，延迟量化精度有限；试验中伺服响应占比较大（18.1 ms 的机械滞后），非感知计算所致；
- **测试场景覆盖有限**：15 种几何均为静态接触，未涵盖动态接触、滑移、非刚性形变等更复杂工况。
