## 摘要
脉冲神经网络（SNN）通过离散时间事件处理信息，为传统人工神经网络提供了一种高能效的神经形态替代方案。本文介绍了一种针对MNIST数字分类优化的仅推理SNN加速器的设计与现场可编程门阵列（FPGA）实现。为了应对低成本器件中固有的物理布线约束和时序瓶颈，我们提出了一种优化的硬件微架构，其特点包括：由有限状态机（FSM）控制的时分复用1位脉冲馈送机制、用于权重存储的局部分布式存储器，以及基于整数的漏电积分放电（LIF）神经元模型，其寄存器宽度经过选择以防止溢出。此外，一个多周期流水线化的argmax和决胜读出模块消除了主要的组合逻辑关键路径。在采用784-64-10网络拓扑的入门级AMD Artix-7 FPGA（XC7A200T）上实现后，所提出的流水线架构将最大工作频率（Fmax）从13.3 MHz提高到167 MHz。硬件评估表明，每张图像的顺序处理延迟为82微秒，使得1000个样本的VHDL仿真批次能够在0.082秒内完成。Vivado实现后的基于矢量的功耗分析估计，片上总功耗为0.336 W，能效约为每焦耳36,300个样本。这些结果表明，只要网络规模保持在时分复用执行的实际限制内，所提出的微架构为实时神经形态边缘推理提供了一种资源高效的解决方案。

## Abstract
Spiking Neural Networks (SNNs) provide a power-efficient neuromorphic alternative to traditional artificial neural networks by processing information through discrete temporal events. This paper presents the design and Field-Programmable Gate Array (FPGA) implementation of an inference-only SNN accelerator optimized for MNIST digit classification. To address the physical routing constraints and timing bottlenecks inherent in low-cost devices, we propose an optimized hardware microarchitecture featuring a time-multiplexed 1-bit spike-feeding mechanism governed by a finite state machine (FSM), localized distributed memory for weight storage, and an integer-based Leaky Integrate-and-Fire (LIF) neuron model with register widths selected to prevent overflow. In addition, a multi-cycle pipelined argmax and tie-breaker readout module eliminates the dominant combinational critical path. Implemented on an entry-level AMD Artix-7 FPGA (XC7A200T) using a 784-64-10 network topology, the proposed pipelined architecture increases the maximum operating frequency (Fmax) from 13.3 MHz to 167 MHz. Hardware evaluation demonstrates a sequential processing latency of 82 μs per image, enabling a 1,000-sample VHDL simulation batch to be completed in 0.082 s. Vivado post-implementation vector-based power analysis estimates the total on-chip power consumption at 0.336 W and the energy efficiency at approximately 36,300 samples per joule. These results demonstrate that the proposed microarchitecture provides a resource-efficient solution for real-time neuromorphic edge inference, provided that the network size remains within the practical limits of time-multiplexed execution.

## 核心思想

将 SNN 推理任务划分为**三个流水阶段**——摄入（Ingestion）、处理（Processing）、决策（Decision），通过**时间复用（Time-Multiplexing）** 将空间密集连接转化为时序串行操作，从而大幅缓解布线压力；通过**多周期流水线化（Multi-cycle Pipelining）** 打破组合关键路径，实现高频运行。

### 关键技术细节

#### (a) 权重量化与 ANN→SNN 转换
- 软件基线：PyTorch 训练 784-64-10 的三层 ANN（Adam 优化器，10 epochs），准确率 97.70%；
- 采用**均匀线性量化**将浮点权重映射为 8-bit 有符号整数：
  - **公式**：$W_{q,l} = clamp(round(S_l \cdot W_{f,l}), -128, 127)$，其中 $S_l = 127 / \max(|W_{f,l}|)$ 为层相关缩放因子；
- 输入采用**速率编码（Rate Coding）**：像素归一化强度决定其在时间窗口 $T$ 内的发放概率。

#### (b) 无乘法器的整数 LIF 神经元模型
- 用**算术右移**实现泄漏（避免乘法/除法代价），离散时间动力学为：
  - **公式**：$V[t+1] = V[t] - (V[t] \gg leak\_shift) + I_{syn}[t]$
- 采用 32-bit 膜电位寄存器防溢出；阈值比较后发放脉冲并清零复位。

#### (c) 参数搜索确定最优配置
- 在 1,000 样本验证集上对阈值 $\theta$（25~650）和泄漏位参数 $leak\_shift$（0~7）进行网格搜索；
- 最优配置：$\theta=450$、$leak\_shift=6$、时间窗口 $T=16$，验证准确率 97.6%；
- 使用 5 个随机种子（42–46）评估算法方差。

#### (d) 时间复用的 1-bit 脉冲广播 + 局部化存储
- 784 个像素通过 FSM 控制逐周期串行广播 1-bit 脉冲到全部 64 个隐藏层突触累加器；
- 每个累加器用全局 pixel_idx 索引本地权重查找表；若脉冲为 1 则累加 8-bit 权重，否则跳过（节省动态功耗）；
- 权重和输入数据在**编译期**通过 VHDL impure function（`load_weights`、`load_spike_patterns`）直接嵌入硬件，避免运行时外部存储接口。

#### (e) 多周期流水线 Argmax 读出引擎（核心优化）
- **V1（基线）**：纯组合逻辑 argmax 树，单周期完成 10 通道比较 + 膜电位决胜，关键路径超 100 级 LUT；
- **V2（优化）**：替换为 5 状态 FSM（IDLE、COMPARE_SPIKE_COUNTS、COMPARE_MEMBRANE_POTENTIALS、REPORT_PREDICTED_LABEL、WAIT_FOR_RESET）：
  - 9 周期顺序比较脉冲计数（$L_{pred} \gets i$ 若 $S_i > S_{L_{pred}}$）；
  - 若所有输出通道均未发放（$\sum S_i = 0$），再花 9 周期比较各通道最终膜电位 $V_i[T]$ 作为决胜；
  - 总延迟 12~22 周期，关键路径被限制在单个比较器内。

#### (f) 集中式 FSM 层控制器
- 10 个确定性状态循环：`IDLE → LOAD_HIDDEN_LAYER（784周期）→ HIDDEN_ISYN_READY → HIDDEN_LIF_PROCESSING → LOAD_OUTPUT_LAYER（64周期）→ OUTPUT_ISYN_READY → OUTPUT_LIF_PROCESSING → OUTPUT_SPIKE_COUNTING → ARGMAX_COMPUTING → RESET_STATE`。

### 分类决策规则
**公式**：Prediction = $\arg\max_i (S_i)$（若 $\sum S_i > 0$）；否则 = $\arg\max_i (V_i[T])$（脉冲全零时以膜电位决胜）。

## 6. 主要结论与发现

1. **频率大幅提升**：从 V1 的 13.3 MHz（75 ns 周期，WNS=+2.023 ns）提升至 V2 的 167 MHz（6 ns 周期，WNS=+0.090 ns）——单一 argmax 流水线改造带来 ~12.5× 的时钟频率提升。
2. **低延迟**：单样本处理延迟从 1.024 ms（V1）降至 82 μs（V2）——相对未优化 Python 软件加速约 1,000×，相对向量化 NumPy 加速 3.4×。
3. **高能效**：SAIF 向量式功耗估计 0.336 W（V2），能效约 36,300 样本/焦耳——相对 V1 提升 6.6×，相对向量化 CPU 提升约 493×。
4. **精度保持良好**：在 10,000 样本 MNIST 测试集上实现 96.70% ± 0.04% 的分类准确率，与基线 ANN（97.70%）的精度差距仅约 1.00%。
5. **资源效率优异**：零 BRAM、零 DSP，仅消耗约 12% LUT 和 3% FF，为在低成本器件上扩展更大网络提供空间。
6. **实时流式能力**：与依赖批量处理的 CPU 不同，V2 可按样本逐张实时处理（82 μs/图），适合边缘流式场景。

## 7. 优点

- **系统化的问题定位**：准确识别了 FPGA SNN 推理的两个核心瓶颈（布线拥塞+组合 argmax 关键路径），并逐一针对性解决。
- **硬件-软件协同设计**：软件端（量化、速率编码、参数搜索）与硬件端（FSM 控制、整数 LIF、流水线读出）形成闭环设计，验证充分。
- **免乘法/免 BRAM/DSP**：右移泄漏 + 分布式查找表存储显著降低资源门槛，适合入门级 FPGA。
- **严格的等价值验证**：VHDL 硬件与 Python 参考模型在整数精度上逐位匹配（bit-accurate），自动化测试平台避免人工波形检查的主观性。
- **清晰的消融设计**：V1→V2 仅调整 argmax 实现，测得的全部性能变化均可归因于该微架构改动。
- **功率分析的精细度**：对比 vectorless 与 SAIF 两种功耗估计方法，显式展示 SNN 稀疏性对动态功耗的影响（V2 从 0.637 W 降至 0.336 W）。
- **可复现性**：公开 GitHub 仓库提供完整实现框架，Vivado 版本、约束策略等实现细节记录详细。

## 8. 不足与局限

- **数据集覆盖有限**：仅 MNIST 单一基准，未涉及 Fashion-MNIST、N-MNIST、DVS-Gesture 等更复杂或原生事件驱动数据集，泛化性存疑。
- **仅推理、不支持学习**：无片上/在线学习能力；网络训练完全依赖软件离线完成。
- **功耗为仿真估计而非物理测量**：虽然采用 SAIF 后布线功耗分析优于 vectorless，但仍属 CAD 工具估计，未在板级进行实际功耗实测。

- **速率编码效率限制**：对于稀疏事件型负载，速率编码不如时序编码/阶序编码能充分利用脉冲稀疏性。
