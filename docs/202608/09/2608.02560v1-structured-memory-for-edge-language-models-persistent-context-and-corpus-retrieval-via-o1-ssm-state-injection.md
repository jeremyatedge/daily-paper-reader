## 摘要
检索增强生成（RAG）的预填充成本与检索上下文长度成正比，并且在基于Transformer的骨干网络中，KV缓存会随着生成的每个词元而增长。状态空间模型（SSM）从根本上避免了第二种成本；我们消除了第一种成本，将每查询的预填充从O(L_context)降低到O(1)。我们提出了PRECOG（预计算上下文注入），这是一种利用SSM特有属性的检索机制：固定大小、位置无关的循环隐藏状态是模型已读取内容的完整摘要。PRECOG在离线时将文档语料库预编码为SSM隐藏状态，并在查询时直接注入最佳匹配状态，完全绕过了上下文中的重新摄取。相同的状态注入机制实现了SMC（结构化记忆整合）：一种具有认知领域聚类的分层持久记忆，一个可调节的保真度与存储旋钮，以及O(1)的会话初始化，它将短期情景状态整合为长期语义记忆，并在查询时将两者与检索到的语料库状态融合。我们在TENNs-LLM上演示了该系统，这是一个具有192 KB隐藏状态的12亿参数门控SSM语言模型。PRECOG在答案质量上与上下文RAG相匹配，将边缘硬件上的预填充延迟从约27秒降至小于6毫秒——约4500倍的加速，跨越了从不可用到交互式的阈值。这种机制在架构上对于Transformer KV缓存是不可能的，因为KV缓存与位置纠缠且随上下文长度线性增长。

## Abstract
Retrieval-augmented generation (RAG) imposes a prefill cost proportional to retrieved context length, and -- with Transformer backbones -- a KV-cache that grows with each generated token. State-Space Models (SSMs) avoid the second cost by construction; we eliminate the first, collapsing prefill from $O(L_{context})$ to $O(1)$ per query. We introduce PRECOG (Pre-Computed Context Injection), a retrieval mechanism that exploits a property unique to SSMs: the fixed-size, position-agnostic recurrent hidden state is a complete summary of everything the model has read. PRECOG pre-encodes document corpora offline as SSM hidden states and injects the best-matching state directly at query time, bypassing in-context re-ingestion entirely. The same state-injection mechanism enables SMC (Structured Memory Consolidation): a hierarchical persistent memory with cognitive-domain clustering, an adjustable fidelity-vs-storage dial, and $O(1)$ session initialization, which consolidates short-term episodic states into long-term semantic memory and fuses both with retrieved corpus states at query time. We demonstrate the system on TENNs-LLM, a 1.2B-parameter gated-SSM language model with a 192 KB hidden state. PRECOG matches in-context RAG answer quality, reducing prefill latency from $\sim$27 s to $<$6 ms on edge hardware -- a $\sim$4500$\times$ speedup that crosses the threshold from unusable to interactive. The mechanism is architecturally impossible for Transformer KV-caches, which are position-entangled and grow linearly with context length.

- **背景与动机**：Retrieval-Augmented Generation（RAG）在 Transformer 上存在两大结构性缺陷：  
  - 预填充（prefill）成本随检索上下文长度线性增长（O(L_context)），边缘设备上 512 token 的预填充需约 27 秒，无法交互；

- **核心问题**：如何彻底消除 RAG 的上下文摄取（context ingestion）成本，使边缘语言模型能在有限算力和带宽下实现实时检索与持久记忆。
- **整体含义**：论文利用状态空间模型（SSM）独有的**固定大小、位置无关的循环隐藏状态**特性，提出 PRECOG（Pre-Computed Context Injection）机制，将预填充从 O(L_context) 降为 O(1)，使“状态注入”成为可替代“token 再摄取”的通用计算原语，并扩展出结构化持久记忆 SMC。这一机制在 Transformer 体系下从架构上不可能实现。
- 该工作为边缘 LLM 提供了一种“检索即状态加载”的新范式，使 1.2B 参数模型在边缘硬件上的首次响应延迟跨越从不可用到交互式的阈值（≈4500 倍加速）。

### 2. 方法论

- **核心思想**：SSM 的隐藏状态是模型已读内容的完整摘要，且更新映射 Φ(h,x) 只依赖当前 token 与状态，无显式时间/位置依赖（时间平移不变性）。因此，预先对语料库各 chunk 编码并保存其最终隐藏状态，查询时直接注入该状态，等价于在上下文中重新摄取这些 token。
- **PRECOG 机制**：
  - **离线索引**：将知识库划分为固定长度 chunk（默认 512 token），用 SSM 推理模式编码每个 chunk，捕获 24 层最终隐藏状态（FP16，共 192 KB）；用轻量句编码器（all-MiniLM-L12-v2，384 维）生成检索键，键向量入 DRAM（FAISS 索引），完整状态存 flash，按需加载。
  - **查询注入**：编码查询 → FAISS top-k 检索（默认 k=3）→ 从 flash 加载状态 → 将 top-1 状态写入 SSM 递归状态作为初始条件 → 仅处理查询 token 并生成。
  - **复杂度**：上下文摄取为 O(1)；剩余开销为查询编码（~5 ms）、检索（<1 ms）、状态加载（~50 μs）和拷贝（<1 ms），总计 ~6 ms。
- **理论保证（Theorem 1）**：对于任意初始状态 h0、上下文 c 和查询 q，S(h0, c⊕q) = S(S(h0, c), q)。即 PRECOG 与 in-context RAG 产生相同状态轨迹（精确算术下），FP16 下误差界约为 2^-10·‖h‖。该性质对 Mamba、Mamba-2 等门控/选择性 SSM 同样成立；Transformer 因旋转位置编码导致时间平移不变性失效而被排除。
- **SMC（结构化记忆整合）**：在状态注入基础上构建分层持久记忆：
  - **认知域聚类**：5 个认知域（情感、时间、社交、空间、事实），两阶段路由；子簇分 Type-A（精确时间事件）和 Type-B（压缩模式）。
  - **保真–存储旋钮（K 参数）**：K=Nc（无损情景）、K=Nc/k（可调）、K=1（仅语义，即 PRECOG 状态）。
  - **语义整合**：各子簇维护指数移动平均语义状态 s_mj，会话初始化时直接注入该状态，实现 O(1) 会话启动。
  - **联合检索**：查询时并行检索情景记忆与语料库状态，用 softmax 加权组合成最终初始状态。

### 3. 实验设计

- **主实验**：SQuAD v1.1 dev 集（随机 1000 问子集），在 SQuAD 微调后的 TENNs-LLM 上对比三种配置：
  - ① in-context RAG（gold 段落拼接到问题前）；
  - ② PRECOG top-1 状态注入；
  - ③ PRECOG top-3 softmax 加权组合。
  - 指标：token 级 EM / F1（官方评估脚本）。
- **消融实验**：
  - **注入深度（SQuAD v1.1）**：8 种层子集配置（全 24 层、bottom_18/12/6、top_12/6、每隔一层、零上下文基线），验证低层主导上下文聚合。
  - **Top-k 组合（HotpotQA-distractor）**：k=1/2/3/5/10，对比 Recall@k 与 F1，验证多跳推理中组合噪声。
  - **Chunk 长度敏感性（Natural Questions）**：按 token 长度分桶（<100 至 ≥2400），对比 PRECOG 与 in-context RAG 的 F1 差距，刻画记忆地平线。
- **SMC 聚类验证**：用《哈利波特》电影 1–6 集构建原型、第 7 集作为 held-out 情景记忆流，评估 5 域分离度（inter/intra 距离比值）及“Others”分组中涌现子簇的可探测性。

### 6. 主要结论与发现

- PRECOG top-1 与 in-context RAG 在 SQuAD 上质量几乎一致（EM 58.0 vs 58.2，F1 73.4 vs 73.6），符合 Theorem 1 的 FP16 量化界（差异 ≤0.2）。
- 预填充延迟从 ~27 s 降至 <6 ms，约 4500 倍加速（TTFT 585 ms），使边缘检索从不可用变为交互式。
- 状态注入机制对 Transformer KV 缓存不成立：位置纠缠 + 线性存储增长导致结构上不可行。
- 记忆地平线：SSM 状态对远端 token 有指数遗忘，PRECOG 精确继承骨干模型记忆特性；当 chunk >600 token 时，PRECOG 与 in-context RAG 出现显著差距（NQ 上长桶 F1 差距达 15）。
- 底部层注入保留绝大部分质量（bottom_12 为 99% 全层 F1，存储减半）；高层单独注入失败。
- Top-k 组合在 HotpotQA 上 k=2–3 最优，更大 k 导致组合噪声覆盖多跳收益。

### 7. 优点

- **理论严谨**：以 Theorem 1 将“等价性”从实验期望提升为数学保证，明确刻画 FP16 误差界，并解释 Transformer 失败的架构原因。
- **创新性强**：首次提出“预计算状态注入”替代 token 级上下文摄取，将 RAG 预填充重构为 O(1) 状态拷贝；且无需 PRECOG 特定训练，适用于任何位置不变 SSM。
- **工程实用**：192 KB 状态大小使语法库级检索在存储/带宽上可行；给出完整的平台对比（UFS/LPDDR/DDR/HBM）、Roofline 分析和可复现计算细节。
- **统一框架**：将语料库检索与设备持久记忆统一在同一状态注入基板（PRECOG + SMC），可扩展性强。
- **消融设计精细**：区分检索错误与组合错误、验证层位置 vs 密度、量化存储-质量折衷。

### 8. 不足与局限

- **理论有限性**：Theorem 1 仅对单 chunk top-1 注入严格成立；top-k 加权组合为启发式，无等价性保证，k 增大时质量下降。
- **实验覆盖不足**：仅一个 QA 基准（SQuAD）+ 两个消融数据集；未在通用语言任务、多语言、开放生成上验证；未与其他 SSM 检索方法（PICASO、State Soup、Memory Caching）在同等条件下对比；无 SMC 端到端问答评测。
- **记忆地平线限制**：PRECOG 无法超越骨干模型本身记忆能力，超长 chunk 下信息丢失；需依赖 chunk 切分或骨干改进，未提出解决方案。
- **存储代价**：每 chunk 状态 192 KB 较原始文本（~1 KB）高约 200 倍；在存储受限场景不适用。
- **部署数据可信度**：神经形态芯片功耗/能效为 12nm 模拟值，FPGA 测吞吐未测功耗；缺少实地验证。
- **潜在偏差**：SMC 聚类验证使用《哈利波特》虚构对话和 GPT-4o 生成标签，可能与真实设备交互分布不符；SQuAD 是抽取式 QA，不能反映自由生成中状态注入的语义保真。
