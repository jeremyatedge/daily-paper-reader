## 摘要
指数函数和Sigmoid等非线性函数在AI和大语言模型加速中至关重要，但在FPGA上高效实现它们仍然代价高昂。本文提出了一种基于部分重配置的PWL插值框架，以降低硬件成本同时保持灵活性。该架构将设计分为用于通信和控制的静态区域，以及一个可动态加载不同插值模块的可重配置区域。针对指数函数和Sigmoid函数，使用FP16和FP32算术评估了均匀和非均匀分段策略。结果表明，非均匀分段可以提高高曲率区域的精度，而均匀分段则具有较低的硬件开销。在系统层面，与同时包含两种运算器的静态设计相比，可重配置实现实现了显著的面积节省，LUT减少高达43%，触发器、BRAM和DSP单元减少高达50%；所有这些都具有可预测的重配置延迟。这些结果表明，部分重配置是在基于FPGA的LLM工作负载非线性函数加速中探索面积-延迟权衡的一种实用方法。

## Abstract
Non-linear functions such as exponential and sigmoid are essential in AI and LLM acceleration, although implementing them efficiently on FPGAs is still costly. This paper proposes a PWL interpolation framework based on partial reconfiguration to reduce hardware cost while preserving flexibility. The architecture separates the design into a static region for communication and control, and a reconfigurable region where different interpolation modules can be dynamically loaded. Uniform and non-uniform segmentation strategies are evaluated for exponential and sigmoid functions using FP16 and FP32 arithmetic. Results show that non-uniform segmentation can improve accuracy in high-curvature regions, while uniform segmentation offers lower hardware overhead. At the system level, the reconfigurable implementation achieved significant area savings, reaching up to 43\% less LUTs, 50\% less flip-flops, BRAMs and DSPs cells, compared against a static design containing both operators; all this with predictable reconfiguration latency. These results show that partial reconfiguration is a practical approach for exploring area-latency trade-offs in FPGA-based acceleration of non-linear functions for LLM workloads.

- **研究背景**：大语言模型（LLM）计算复杂度高、对硬件资源需求大，在资源受限环境中的部署面临挑战。尽管现有硬件加速研究多集中于卷积和矩阵乘法等线性代数运算，但现代 ML 架构同样依赖计算密集的非线性函数（如指数、sigmoid、softmax、层归一化中的运算），这些函数在 GPU 运行时中占据显著比例，却往往不如线性代数核那样被优化。
- **核心问题**：在 FPGA 等资源受限平台上，指数、sigmoid 等非线性函数的硬件实现成本高昂（需要大量逻辑资源、BRAM、DSP 等），同时精确计算开销大。如何在降低硬件成本、延迟和功耗的同时，保持可接受的精度与推理性能，是一个关键挑战。
- **整体含义**：本文提出一种基于**部分重配置（Partial Reconfiguration, PR）**的 PWL（分段线性）插值框架，将静态控制区域与可动态加载的插值计算区域分离，在硬件资源受限场景下实现面积-延迟-灵活性之间的权衡，为 FPGA 上的 LLM 非线性函数加速提供了新思路。

## 2. 论文提出的方法论（核心思想、关键技术细节）

- **核心思想**：采用**时间复用（time-multiplexed）**的加速器架构。系统被分为：
  - **静态区域（Static Region）**：负责通信与控制，包含 Zynq UltraScale+ MPSoC（目标频率 100 MHz）、AXI SmartConnect、AXI Shutdown Manager、AXI GPIO。
  - **可重配置区域（Reconfigurable Region）**：可动态加载不同的 PWL 插值引擎（指数、sigmoid 等），同一时刻只实例化一个插值模块，从而节省面积。
- **PWL 插值原理**：对于相邻断点 x₁、x₂，用线性方程 f(x) ≈ m(x + b/m) 来近似，其中 m 为斜率、b 为截距。采用**斜率因子化**形式以避免快速增长函数（如指数）中的系数溢出。
- **分段策略**：
  - **均匀分段（Uniform）**：断点在输入范围内等间距分布，索引计算仅需算术运算，硬件开销低。
  - **非均匀分段（Non-Uniform）**：根据函数曲率（与二阶导数成比例）在高曲率区域分配更密集的断点，需要**二叉搜索**进行索引查找（避免比较器链的高延迟和低可扩展性）。
- **数据流与接口**：采用 load-compute-store 结构。静态区域负责数据搬运（AXI4 协议），可重配置区域负责解包/打包（支持不同数值精度）、索引搜索和插值计算。插值仅需一次乘法和一次加法完成。
- **系数存储**：使用 LUT-RAM 存储小规模系数表（替代 BRAM）。
- **数值精度**：支持 FP16 和 FP32 两种算术格式。
- **软硬件协同**：采用 PYNQ 作为 Linux 运行时的轻量级 DFX 管理环境，通过 MMIO 寄存器实现软件控制的关闭/复位握手、硬件元数据导出和动态区域控制。
