## 摘要
基于Transformer的深度学习模型的出现，在自然语言处理和计算机视觉等多个领域带来了前所未有的性能表现。然而，由于这些模型具有较高的计算复杂度以及较大的内存占用和带宽需求，将其部署到资源受限的设备上仍然面临重大挑战。这种复杂性促使研究人员采用低位宽的模型权重来减少内存占用并提升效率。除了降低处理和内存需求外，量化还引入了另一个有用的特性：值局部性，即极大量的参数被限制在一个有限的值域范围内。为了充分利用这种局部性，本文提出了DeVIT，一种利用差分计算实现无乘法器矩阵乘法的视觉Transformer加速方法。

## Abstract
The emergence of transformer-based deep learning models has brought unprecedented performance across various domains, particularly in natural language processing and computer vision. However, deploying these models, especially on resource-constrained devices, poses significant challenges due to their high computational complexity and large memory size and bandwidth requirements. This complexity has led researchers to use low-bit model weights to reduce memory usage and improve efficiency. In addition to reducing processing and memory demands, quantization introduces another useful property: value locality, where the extremely large number of parameters are restricted to a limited range of values. To fully take advantage of this locality, this paper presents DeVIT, an acceleration method for vision transformers that leverages differential computation to enable multiplier-less matrix multiplication.

# DeVIT：基于差分计算的低功耗视觉Transformer加速——论文总结

## 1. 核心问题与研究动机

- **背景**：Vision Transformer（ViT）在图像处理任务上表现出色，但其计算复杂度和内存需求远高于CNN。例如，ViT-B/16 含有 8600 万参数，处理单张 224×224 图像需 176 亿次 MAC 运算，是 ResNet-50 的 4 倍以上；ViT-L/16 则需 610 亿次 MAC。
- **核心问题**：在资源受限设备（边缘端、嵌入式）上高效部署 ViT 面临严峻挑战——高计算量、大内存占用和高带宽需求。
- **已有方案与不足**：低比特量化可缓解存储压力，但量化后的模型仍需大量乘法运算（MAC）。
- **关键洞察**：量化引入了一个此前未被充分利用的副产品——**值局部性**（value locality）。8-bit 量化下每个权重仅有 256 种取值，而 ViT 权重矩阵极大，几乎每行都会覆盖全部量化取值，这意味着**同一个输入元素会被乘以几乎所有可能的量化权重值**——为计算复用提供了天然基础。

## 2. 方法论：DeVIT 的核心思想与技术细节

### 2.1 核心思想
利用量化权重的值局部性，将矩阵乘法中的乘法运算转化为**差分计算 + 移位/加法**，实现无乘法器的推理。

### 2.2 差分计算原理
- 将权重矩阵每行按升序排序，以**差分格式**（delta format）存储：ΔW = W₂ − W₁。
- 计算时复用前序结果：
  \[
  a × W₂ = a × W₁ + a × ΔW
  \]
- 由于量化后权重值集中，ΔW 大多很小（0、1、2 为主），可将其近似为**最近的 2 的幂**，从而用移位操作替代乘法。
- **零 delta** 直接跳过计算，复用前一结果。

### 2.3 数据流设计
- 采用**输入静态（input-stationary）** 数据流：同一输入元素依序乘以对应权重行中的所有权重。
- 每个 delta 值携带目标索引（原始列号），保证排序后累加结果能路由到正确的输出位置。
- 为平衡缓冲区大小与功耗，引入**权重矩阵分区**策略（64/32/16 元素为一组），同时获得部分输出静态特性。

### 2.4 索引编码方案
- 每个 delta 用 **4-bit 编码**：1 位符号位 + 3 位幅度位，表示 {0, 1, 2, 4, 8}，超过 8 的 delta 截断到 8。
- 索引位取决于分区大小：64 元素 → 6 bit，32 → 5 bit，16 → 4 bit。
- **每权重总存储开销**：64 分区 = 10 bit、32 分区 = 9 bit、16 分区 = 8 bit。64 分区相比 8-bit 量化基线有 25% 的存储开销，但换取了全部线性层乘法器的消除。

### 2.5 硬件架构
- 基于 RTL 设计，包含权重缓冲区（存储 delta 编码和目标索引）、移位加法处理单元、输出累加缓冲区和控制器。
- 每个处理单元只需支持**移位和加法**，完全免除乘法器。

## 6. 主要结论与发现

1. **计算大幅压缩**：DeVIT 将归一化计算负载降至基线的 **0.53**，优于 FACT 的 FC1-skip（0.61）和 attention-skip（0.70），较 attention-skip 降低约 24%。
2. **能耗优势**：单 GEMM 能量为 **159.57 nJ**，比 ShiftAddLLM 最低能量配置（168.84 nJ）低约 5.5%。
3. **精度保持**：64 分区配置下，除 Swin Top-1 下降 2.88 个百分点外，其余模型精度下降均低于 1 个百分点。
4. **分区权衡**：分区越小，delta 分布越分散（零 delta 比例降低），计算复用率下降，但索引宽度和缓冲区更小；64 元素是最推荐的折中。

## 7. 优点与亮点

- **创新性**：首次将差分计算系统地应用于 ViT 的矩阵乘法，针对 transformer 的密集 GEMM 结构设计了专门的数据流和分区策略。
- **利用而非抵抗量化副作用**：不把值局部性视为负担，而是将其转化为计算复用的基础，思想巧妙。
- **完全消除乘法器**：推理仅需移位和加法，硬件实现极简，擅长低功耗场景。
- **离线处理、零训练开销**：权重重编码完全离线，应用时无 per-input 预测或在线预计算开销。
- **参数化的分区机制**：通过分区大小可灵活调节精度、存储开销、缓冲区大小和计算复用率的权衡。
- **任务覆盖较广**：涵盖图像分类（ViT/DeiT/Swin）和目标检测（DETR），验证了方法的适用范围。
- 相关工作回顾全面，与新兴方法（ShiftAddViT、ShiftAddLLM、FACT、ViTCoD 等）的定位区分清晰。

## 8. 不足与局限

- **精度损失在马力全开配置下不可忽视**：32 分区配置下，Swin Top-1 下降 3.11 个百分点、DETR mAP 下降 2.53 个百分点。
- **16 分区配置的精度和能量数据缺失**，该配置尽管存储无开销，但实际可用性未经验证。
- **仅评估单 GEMM 能量，无端到端模型推理延迟/吞吐对比**。整体系统级加速效果尚不明确——尤其是索引路由逻辑、软max/LayerNorm 等非 GEMM 部分的开销未纳入核算。
