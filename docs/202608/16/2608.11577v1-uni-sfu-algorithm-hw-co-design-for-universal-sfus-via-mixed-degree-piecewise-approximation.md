## 摘要
非线性激活函数对于现代深度神经网络（DNN）至关重要，但其硬件评估对GPU和定制加速器的特殊函数单元（SFU）造成了显著压力。因此，在允许的误差范围内，通常采用分段多项式逼近来提高计算效率。然而，现有技术往往使用固定阶多项式和均匀分段来孤立地逼近每个激活函数，导致硬件冗余和精度次优。为了解决这些限制，我们提出了Uni-SFU，一种算法-硬件协同设计框架，它联合优化一组多样化激活函数的逼近精度和硅面积。Uni-SFU利用对所有目标函数的联合搜索，在RTL导出的面积成本模型指导下，将混合阶多项式分配给非均匀分段。这种方法确定了一个统一的硬件配置，以在给定精度约束下实现目标激活函数。在超过700种神经网络变体和三种自然语言处理（NLP）模型上的验证表明，Uni-SFU实现了优于8.22x10^-8的均方误差（MSE），与浮点基线相比，将top-1精度下降限制在1.02%以内。所提出的设计在GF 22nm CMOS工艺中仅占用6,800 um²，与最先进的对应方案相比，在硅面积和系统级精度之间实现了优越的权衡。

## Abstract
Nonlinear activation functions are essential to modern deep neural networks (DNNs), but their hardware evaluation places significant pressure on the special-function units (SFUs) of GPUs and custom accelerators. Therefore, piecewise polynomial approximations are commonly used within allowed error bounds to improve computational efficiency. However, existing techniques often approximate each activation function in isolation using fixed-degree polynomials and uniform segments, leading to hardware redundancy and sub-optimal precision. To address these limitations, we present Uni-SFU, an algorithm-hardware co-design framework that jointly optimizes approximation accuracy and silicon area for a diverse set of activation functions. Uni-SFU leverages a joint search across all target functions to assign mixed-degree polynomials to nonuniform segments, guided by an RTL-derived area cost model. This approach identifies a unified hardware configuration to implement the target activation functions under given accuracy constraints. Validated across over 700 neural network variants and three Natural Language Processing (NLP) models, Uni-SFU achieves a superior Mean Squared Error (MSE) below 8.22x10^-8, limiting top-1 accuracy degradation to within 1.02% compared to floating-point baselines. The proposed design occupies only 6,800 um2 in GF 22nm CMOS technology, achieving a superior trade-off between silicon area and system-level accuracy compared to SOTA counterparts.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- 现代DNN中非线性激活函数（如GELU、SiLU、Tanh、Sigmoid等）种类日益多样、计算复杂度高（比ReLU多3×~8× FLOPs），其硬件求值成为GPU/ASIC加速器的重要瓶颈。
- 当前SFU（Special Function Unit）设计通常采用分段多项式逼近（PPA）来平衡精度与硬件开销，但存在两大核心低效：
  - **均匀分段 / 固定阶多项式**：对低曲率区域（如SiLU尾部）也用高阶多项式，浪费存储与计算资源。
  - **逐函数独立优化**：每个激活函数单独设计逼近和硬件配置，未考虑单个SFU需要同时支持多个激活函数的实际场景，导致整体硬件冗余。
- 此外，多线程/多通道并行处理时，朴素复制完整系数存储会导致面积随通道数线性增长。
- 因此，该论文提出 **Uni-SFU**：一种算法-硬件协同设计框架，通过“非均匀分段 + 混合阶多项式”联合优化多个激活函数的逼近精度与统一硬件面积，实现通用、面积高效、高精度的SFU。

## 2. 论文提出的方法论

### 2.1 核心思想
- 对多个目标激活函数进行**联合搜索**，将不同阶多项式（常数Z、线性L、二次Q、三次C）分配给**非均匀分段**，并由**RTL综合导出的面积模型**直接指导硬件配置选择（而非用分段数量作为面积代理）。
- 采用**两阶段优化**：
  1. 逐函数生成Pareto最优分段/次数配置；
  2. 跨函数最佳优先搜索（Best-first Dijkstra Search）找到满足所有函数精度约束的最小面积统一硬件配置。

### 2.2 关键技术细节
- **非均匀分段**：初始均匀分段，使用坐标下降法迭代移动断点，直至收敛（≤20次迭代）。
- **混合阶优化（动态规划）**：
  - 状态：累计次数分布 `cd = (cd1, cd2, cd3)`；
  - 状态转移：为当前段选择次数d，更新累计计数（如二次段v(2)=(1,1,0)）；
  - Bellman递推：`Vj(c) = min_d [ Vj-1(c - v(d)) + wj * ej,d ]`；
  - 对每个状态仅保留最小误差的部分分配，通过回溯重建最优次数分配；利用最优子结构保证全局最优（文中给出引理和定理证明）。
- **硬件面积成本模型**：
  - 由RTL综合实验拟合面积公式：`A = Abase(c0,c1,c2,c3) + Acompute(max(d))`；
  - Abase通过多项式回归拟合（含交叉项），Acompute按最大多项式阶数查表；
  - 验证MAPE仅0.83%。
- **跨函数联合优化**：
  - 先计算各函数Pareto集的下界（各次数的最小需求的最大值），作为搜索起点；
  - 在面积优先的优先队列中扩展节点（每次增加Z/L/Q/C中的某一个），第一个可行节点即最小面积通用配置；
  - 确定硬件后，为每个函数重新选择误差最小的可行次数分配，并固定次数再次微调断点。

### 2.3 硬件架构
- 多通道（multi-lane）结构：每个通道复制Breakpoint Comparator、Local Cache、Execution Unit；共享一个Global Multi-Level LUT。
- 局部缓存（Local Cache）利用输入局部性，降低全局LUT访问频率，减少复制面积开销。
- 全局LUT分成四个独立bank（对应Z/L/Q/C系数），支持运行时重加载以支持不同激活函数。
- 流水线化执行：命中时延迟11~16周期，未命中时增加额外访存周期；峰值吞吐为一个输出/通道/周期。
