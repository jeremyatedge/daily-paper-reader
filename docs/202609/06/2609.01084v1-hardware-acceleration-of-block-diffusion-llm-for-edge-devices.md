## 摘要
单流（批量为一）边缘推理无法在请求之间分摊权重传输开销。全注意力扩散大语言模型在每一步都重新计算整个序列；原生块扩散使已完成的块不可变且可精确缓存，但精炼阶段仍需要流式传输前缀键值缓存和前馈网络权重。我们共同设计了WIFiV-LPDDR——一种支持精度标记读取的宽I/O LPDDR系统，BRQ-KV——一种规范的低秩加INT8残差前缀，具有基于查询的逐条目精度选择，以及DAT-FFN——用于漂移映射的规范替换、相邻阶段校正的低比特增量或缓存状态传递，同时保持活动激活值不被量化。所有这些都映射到输入驻留的混合精度脉动阵列。对于评估的1.5B/7B模型，在模拟的Jetson类平台上，完整技术栈在报告的DAT-FFN设置下提供了算术平均能量降低因子3.79倍/3.96倍和算术平均延迟加速比2.88倍/4.44倍；每个对应的压缩模型基准分数相比基线下降不到一个绝对百分点。

## Abstract
Single-stream (batch-one) edge inference cannot amortize weight traffic across requests. Full-attention diffusion LLMs recompute the entire sequence at every step; native block diffusion makes completed blocks immutable and exactly cacheable, yet refinement still streams prefix KV and FFN weights. We co-design WIFiV-LPDDR, a wide-I/O LPDDR system for precision-tagged reads, BRQ-KV for a canonical low-rank-plus-INT8-residual prefix with query-dependent per-entry precision, and DAT-FFN for drift-mapped canonical replacement, adjacent-stage-corrected low-bit delta, or cached-state carry while keeping live activations unquantized. Both map to an input-stationary mixed-precision systolic array. For the evaluated 1.5B/7B models on modeled Jetson-class platforms, the full stack provides arithmetic-mean energy-reduction factors of 3.79x/3.96x and arithmetic-mean latency speedups of 2.88x/4.44x at the reported DAT-FFN settings; every corresponding compressed model-benchmark score drops by less than one absolute percentage point from its baseline.

## 一、论文的核心问题与整体含义

- **任务场景**：论文聚焦“私有设备上的 batch-one LLM 推理”，即每个请求独立进行边缘端推理，无法像云端服务那样跨请求合并批次
- **动机与背景**：
  - **单流推理的固有瓶颈**：batch size=1 时，权重无法在多个请求间复用；自回归解码过程中每一步只生成一个 token，权重复用率极低
  - **全注意力扩散 LLM 的问题**：虽然能够并行预测多个 mask 位置，但每一步都重算整个序列，响应保持可变，无法精确缓存已完成前缀
  - **原生块扩散的不足**：Fast-dLLM v2 将已完成块视为不可变且可精确缓存的单元，但精炼（refinement）阶段仍需从 DRAM 重复读取前缀 KV 和静态 FFN 权重
- **核心研究问题**：如何通过**软硬件协同设计**压缩并优化块扩散 LLM 精炼阶段反复流式读取 KV 缓存和 FFN 权重的开销，使边缘设备能够以接近全精度的质量运行扩散 LLM
- **整体意义**：论文将存储系统设计、近似算法与硬件加速器架构统一为端到端堆栈，解决了边缘端单流扩散推理中指令级“权重数据搬运”这一关键瓶颈

## 二、论文提出的方法论

论文提出了三项核心技术创新，并映射到统一的输入驻留混合精度脉动阵列上：

### 1. WIFiV-LPDDR——宽 I/O LPDDR 存储架构
- **器件/电路/封装的协同设计**：
  - 采用 4F² 垂直沟道晶体管（VCT）与 CMOS 键合阵列（CBA）结构的 DRAM 单元阵列，提高密度
  - CBA 边界允许阵列与外围逻辑使用独立工艺与热预算，外围逻辑采用 FinFET 晶体管，利用更强的驱动电流降低传播延迟（\(t_{pd} \propto C_{eff} V_{DD}/I_{drive}\)）
  - 通过 2.5D 硅中介层与微凸点接口扩展有效 DQ 宽度，并利用细间距 2.5D 集成降低每比特互连能量
- **精度标记读取机制**：
  - 存储规范 q8 码，读取时接受“精度标记”，只需传输请求的低比特有效负载
  - 峰值带宽公式：\(BW_{peak} = \eta_{link} N_{DQ} R_{pin}/8\)
  - 一阶数据搬运能量模型：\(E_{move}(p) = 8e_{core} + p e_{down} + E_{xcode}(p)\)，其主导项与传输比特数成正比，因此降低精度直接减小带宽需求、传输延迟与搬运能量

### 2. BRQ-KV——块刷新查询排序 KV 传输机制
- **典型持久表示**：前缀完成 N_min=128 个 token 后执行一次性预 RoPE 秩-2 基分解
  - 为每层/每头计算固定基矩阵 \(U_K\), \(U_V\)（秩 r_kv=2），Keys 在 RoPE 前分解，Values 直接分解
  - 存储形式：系数矩阵 \(C_K, C_V\)、条目级带符号 INT8 残差码、固定 BF16 基矩阵；残差主副本保持 q8 格式，q4/q2/q0 为只读推导视图
- **重建公式**：\( \hat{x}_i^{(\tau)} = c_i U^T + \mathcal{Q}_\tau(r_i^{(8)}) \)，其中 q0 即仅保留低秩基、丢弃残差
- **块刷新查询排序**：每个新解码块的第二步以当前 S-token 查询组对全前缀做排序，生成位置到精度档位（q8/q4/q2/q0）的映射；后续兼容步骤复用该映射，直到块/跨度完成时失效
- **关键优势**：基于固定累计预算，按查询向量对逐条目分配精度，低精度条目之后仍可升档，且无条目被驱逐（每个前缀 KV 条目都通过低秩基保持活跃）

### 3. DAT-FFN——漂移自适应分层 FFN
- **FFN 通道的状态分类**：根据当前输入与块入口输入的漂移程度，将各通道动态划分为三类：
  - **q8 替换组**：漂移大的通道流式左乘精确重算
  - **q4/q2 增量组**：通过低比特视图计算轻量增量，并利用校正项修正
  - **q0/免载组**：漂移极小，直接用缓存的状态与输出贡献，不访问当前权重
- **分层残差阶梯**：基于规范 GPTQ-q8 码，用固定映射产生 q4/q2 视图，再拟合相邻档间误差的低秩校正 \(E^{8→4} \approx C^{8→4}(V^{8→4})^T\) 和 \(E^{4→2} \approx C^{4→2}(V^{4→2})^T\)，运行时只更新校正边界，无需重排通道
- **FFN 输出合并公式**：\( Y_t^{out} = Y_{a,t} - R_{a,t}^{(8)} + Q_t^{(8)} + \delta Y_{4,t} + \delta Y_{2,t} \)，同一层的增量计算相对所选视图精确成立
- **锚点刷新**：每个内部步骤后刷新非零层的锚点状态与边界，但不需要重新排序或额外全矩阵投影（刷新成本只与档位边界穿越的通道数相关）

## 六、论文的主要结论与发现

- **Full 配置在每对模型-数据集上都优于任何单一组件**，说明存储架构与算法压缩之间存在正交互补
- **量化收益**（算术平均）：
  - 1.5B：能效降低 3.79×，延迟加速 2.88×
  - 7B：能效降低 3.96×，延迟加速 4.44×
  - 两个单独成分大致贡献：Compression（1.62×/1.79×能效；1.42×/1.67×延迟）、WIFiV-LPDDR（2.12×/2.28×能效；2.37×/3.09×延迟）
- **质量保持**：每个被压缩后的基准分数相对基线降低均小于 1 个绝对百分点
- **趋势解读**：Compression 叠加到 WIFiV-LPDDR 上时，能效下降比延迟下降更明显，说明传输比特节省持续存在，而延迟部分被计算和片上工作所限制
- Prefill 最多仅占测量延迟/能耗的 3%，因此精炼阶段的优化空间是本研究的主要立足依据

## 七、优点

- **端到端软硬件协同设计**：存储架构、KV/FFN 精度算法、加速器数据流三者作为一个完整堆栈共同设计，不存在某一环节孤立优化
- **不丢失任何 KV 条目**：BRQ-KV 的 q0 层仍保留低秩基，所有条目始终存在，可被后续查询升档恢复；相比 MAGE 的二元选择或 Chipmunk 的神经元驱逐更具信息保真度
- **FFN 的锚定与增量机制**：DAT-FFN 的 q8/q4/q2/q0 自适应，只在阈值边界移动时产生校正开销，不需要从零重算大权重矩阵；用固定通道顺序避免了反复排序
- **精度转换记忆侧实现**：q4/q2 是“读时视图”，不写回 q8 主副本，简化一致性问题且大幅削减 DRAM 搬运比特
- **保持 BF16 激活**：活动 Key/Value/FFN 激活不被量化，压缩集中在持久权重/缓存侧，有效避免了激活低比特带来的准确率骤降风险
- **对通用扩散架构稳健**：该方法适用于任何块扩散 LLM，DB=32,S=8 只是具体实例

## 八、不足与局限

- **实验覆盖有限**：只评估了 1.5B/7B 两种模型、Jetson 两类平台；未验证更大的商业边缘设备功率形态（如 Neural SDK 加速器、更先进的 LPDDR6/PCB 集成方案）
- **缺少与基线竞争方法的直接对比实验**：MAGE、Chipmunk、DSTAR 在文章中仅以原理性比较出现，没有同一平台上同等评测
- **缺少 KV 敏感性分析**：KV 预算只由一组校准得到；没有展示 KV 预算低/高位时 DAT-FFN 性能的弹性
- **无实际硬件原型**：评测全部基于 LLMET 模拟器，WIFiV-LPDDR 使用了保守的 4× 带宽假设，所得能效/延迟分项依赖模型校准质量，需要进行真实物理验证
- **评测文本域单一**：全部数据集为代码、数学与指令跟随类文本；没有视觉生成与多模态扩散任务，也没有对比“长上下文/超长文本-生成”等极端长度条件
- **训练成本缺失**：未明确说明一次性校准（GSM8K 训练子集）的算力开销、是否需要在 GPU 上长期运行，以及部署时重新校准所需的成本
- **对精度牺牲的解释有限**：报告了“分数下降≤1个百分点”但未讨论在不同随机种子或重复测试下该差异是否显著；具体从“完整未压缩”模型出发的分数也没有列表展示
