## 摘要
尖峰神经网络（SNN）天然擅长处理时间丰富且稀疏的数据。然而，由于其按时间步进的处理方式，内存访问（特别是对存储在SRAM（静态随机存取存储器）中的突触权重的访问）往往主导总功耗。为解决此问题，且不产生大面积开销，我们提出利用网络中神经元平均发放率的巨大差异，将突触权重高效分配到由多个非均匀大小存储体组成的片上内存中。通过将频繁发放神经元的权重分配给浅层、低访问成本的内存，而将较少被访问的权重分配给更深、高密度的内存，可降低突触权重存储器的平均功耗，而不会产生大的面积开销。为对我们的架构进行基准测试并寻找最佳的内存布局配置，我们基于应用需求和硬件约束进行自动探索。对于在28纳米CMOS工艺中综合的内存设计，我们证明，与传统设计相比，我们的架构可实现高达61%的突触权重存储器访问功耗降低，同时与传统均匀分区且实现类似功耗降低的内存库相比，面积开销降低2.1倍。

## Abstract
Spiking Neural Networks (SNNs) naturally excel in processing temporally rich and sparse data. However, because of their time-stepped processing, memory access, specifically to synaptic weights stored in SRAM (static random-access memory), tends to dominate total power consumption. To address this issue, without incurring a large area overhead, we propose to leverage the greatly varying average firing rate of neurons in the network to efficiently allocate synaptic weights to an on-chip memory consisting of multiple non-uniformly sized memory banks. By assigning weights of frequently firing neurons to shallow, low-access cost memory and less actively accessed weights to deeper, high-density memories, the average power consumption of the synaptic weight memory is decreased without incurring a large area overhead. To benchmark our proposed architecture and find optimal configurations of memory arrangements, we perform an automatic exploration based on application requirements and hardware constraints. For memory designs synthesized in 28-nm CMOS technology, we show that our architecture can achieve a synaptic weight memory access power reduction of up to 61\% compared to a conventional design, with a 2.1$\times$ lower area overhead, as compared to a traditional uniformly partitioned memory bank that achieves a comparable reduction.

### 1. 论文的核心问题与整体含义

- **背景**：脉冲神经网络在新型硬件设计中取得了进展，但在时间步进处理的工作方式下，突触权重存储的读取在总功耗中占比非常高，例如在ESSCIRC[1]、JSSC[2]、TCAS-I[3]等不同芯片设计中，突触SRAM访问功耗占整体功耗的49%~75%。
- **问题**：传统方案会把一个大SRAM拆成多个均匀的小存储段，利用事件驱动跳过未激活的突触访问。虽然可以降低功耗，但随着存储段数量增加，存储器的外围逻辑（译码、敏感放大器等）带来的面积和功耗开销会迅速上升，甚至主导整体设计成本。
- **核心含义**：如果能够利用SNN本身极高的神经元放电不均衡性，将权重放到不同深度的存储体中，就能在不显著增加面积的前提下降低平均访问功耗。

### 2. 论文提出的方法论

- **核心思想**：在完整推理网络中，预神经元的平均放电频率差异很大。大多数访问都集中在少数高频放电神经元对应的突触权重上。
  - 根据放电频率排序的结果，把高频放电神经元的突触权重放进**较浅、密度低但单位访问功耗小**的SRAM Bank中。
  - 把低频访问的权重放进**更深、密度更高**的SRAM Bank中，从而在不增加面积开销的情况下降低平均存储访问功耗。
- **非均匀存储系统结构**：
  - 逻辑上将多个非均匀大小的预编译SRAM宏拼接成一个连续地址空间，不需要从控制器一侧查找权重所在具体Bank。
  - 地址的低位段对应浅层Bank，随地址升高逐步进入更深、更不易访问的Bank。
  - 权重排序方式保证地址越低，期望访问频率越高，这样硬件无需额外控制逻辑或查找表，而只需在地址发生变化时自动映射。
- **控制器和地址映射设计**：
  - 对全连接层，将预神经元按放电率排列，预神经元ID作为LSB，方便直接按连续递增地址顺序访问权重。
  - 对卷积层，则利用同一卷积核权重在不同位置上具有近似访问频率的特点，按输入通道的活动率对通道权重进行排序，通过按通道顺序访问来控制Bank的映射，无需额外缓存。
- **多Bank控制逻辑**：
  - 时钟门控（CG）：停掉未激活Bank的时钟，降低动态功耗。
  - Bank选择解码器：根据输入权重地址与原 Bank 深度比较产生独热使能信号。
  - 输出选择逻辑：根据上一位“读选择”信号选择正确的输出，避免非对齐等待。
  - 地址偏移控制：计算每个Bank内部的偏移地址，使得外部看待存储就像单一连续的内存，见Fig.3中的结构。
- **自动设计空间探索**：
  - 给定存储总容量（32KB 或 64KB）、可用的SRAM宏尺寸范围（限制1KB到32KB），自动搜索全部内存宏组合。
  - 每种组合自动生成Verilog硬件代码，进行综合、功耗评估，并对读取访问频率进行仿真（基于采集的神经元活动与网络拓扑）来挑选最优配置。
  - 最终可通过探索找到最佳分配方案，兼顾面积开销和读功耗。

### 6. 论文的主要结论与发现

- 非均匀SRAM可以减少突触存储访问功耗，而不会在面积上产生同比例增长。
  - 在 DVSGesture 和 N-MNIST 上分别可以获得最多 63% 和 61% 的功耗降低（在配置C/D中）。
  - 对比均匀分块方案，例如配置D（2×8KB 和 8×2KB）相比均匀8×4KB的方案，功耗降低相近，但 **面积开销从38%降到18%** —— 即 **2.1 倍更低面积开销**。
- 访问分布支持该方案：
  - 对于卷积网络，10%的权重贡献了54%~71%的总访问量。
  - 在全连接网络中，则通常为 33%~55%，但仍是显著集中分布。
- 控制逻辑的面积开销极低，不到整个存储器面积的1%，不增加额外时钟周期。

### 7. 优点

- 思路直接利用了SNN自身的稀疏事件机制和非均匀发放行为，简化了硬件逻辑，避免了大规模查表。
- 非均匀存储将“低成本浅存+高密度深存”结合，达到了能效和面积之间的有效平衡。
- 提供了自动设计探索框架，可以综合不同网络与资源约束找到最优存储配置，对工程化采用有较高价值。
- 实验覆盖了视觉、语音事件的数据类型，以及不同SNN拓扑，展示了方法的普适性，多个数据集结果可以相互印证。
