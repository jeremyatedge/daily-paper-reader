## 摘要
随着神经推理和传感器边缘分析等现代数据密集型应用的扩展，它们日益遭遇冯·诺依曼内存墙，承受过度的数据搬运开销和严格的能耗约束。利用新兴非易失性技术（如磁隧道结MTJ）的存内计算（IMC）有望缓解这些瓶颈。然而，传统的基于二进制基数的IMC架构存在对工艺引起的变异的过度敏感性、工作裕度受限以及热噪声等问题。为了弥合能效与计算可靠性之间的差距，本工作提出了FALCON，一种与随机计算（SC）集成的、基于MTJ的容错存内算术架构。通过将数值编码为均匀比特流，SC自然吸收了局部软错误，并使得在存储阵列内部直接使用高度紧凑的逻辑原语执行一组基本算术运算成为可能。FALCON将确定性比特映射机制与可重构逻辑存内（LIM）结构相结合，无需将数据传送到外部处理器或使用面积和功耗密集的随机数生成器。使用14纳米FinFET技术的实验结果验证了即使在高强度电压缩放、严重工艺变异性以及高达30%的噪声注入水平下，FALCON仍能正确运行，这使其成为面向可靠性关键边缘AI应用的稳健框架。我们还以形态学闭合作为实际抗噪图像处理案例研究了FALCON的适当功能。

## Abstract
As modern data-centric applications such as neural inference and sensor-edge analytics expand, they increasingly encounter the von Neumann memory wall, suffering from excessive data movement overhead and stringent energy constraints. In-Memory Computing (IMC) utilizing emerging non-volatile technologies, such as Magnetic Tunnel Junctions (MTJs), promises to mitigate these bottlenecks. However, conventional binary radix-based IMC architectures suffer from excessive vulnerability to process-induced variations, restricted operating margins, and thermal noise. To bridge the gap between energy efficiency and computational reliability, this work proposes FALCON, a fault-tolerant, MTJ-based in-memory arithmetic architecture integrated with Stochastic Computing (SC). By encoding numerical values into uniform bit-streams, SC naturally absorbs localized soft errors and enables the execution of an essential suite of arithmetic operations using highly compact logic primitives directly within the memory arrays. FALCON integrates a deterministic bit mapping mechanism with reconfigurable logic-in-memory (LIM) structures, eliminating the need to transfer data to external processors or area- and power-hungry random number generators. Experimental results using 14 nm FinFET technology validate the correct functionality of FALCON even under aggressive voltage scaling, severe process variation, and noise injection levels up to 30%, making it a robust framework for reliability-critical edge AI applications. We investigate the proper functionality of FALCON on morphological closing as a realistic noise-tolerant image processing case study.

## 2. 论文提出的方法论

### 核心思想
将数值编码为均匀比特流，通过 SC 的概率表示天然吸收局部软错误——任意单比特翻转仅贡献一个最小单位的扰动，对最终数值影响极小。同时，SC 中复杂算术运算被简化为 AND、OR、XOR、MUX 等紧凑逻辑原语，可直接在 MTJ 存储阵列内部实现。

### 三层端到端架构（图 2）

FALCON 将完整算术工作流"搬进"MTJ 存储阵列内，包含：

1. **二进制到比特流编码器（前端）**
   - 采用**确定性低差异（LD）比特映射**机制。
   - 对于 n 位二进制输入 X，每一位 Xi 被复制 \(2^i\) 次，按照预定义的 LD 模式（Pattern 1/2/3 等）放置在长度为 \(2^n\) 的比特流中的特定位置。
   - 无需任何随机数生成器/伪随机序列，彻底消除 SC 系统传统上最昂贵的面积-功耗开销来源。
   - **相关性控制的关键设计**：对两个输入施加**相同 LD 模式** → 得到相关比特流（用于 Min/Max/绝对减法）；施加**不同 LD 模式** → 得到近似独立的比特流（用于乘法）。

2. **可重构逻辑存内（LIM）算术单元（中端）**
   - 每个 LIM 单元包含 MTJ1、MTJ2 和参考 MTJ3。
   - **准备阶段**：两个输入比特流以双向写电流驱动编程，将 MTJ 配置为 P（低阻）/AP（高阻）状态，产生四种阻值组合（HH/HL/LH/LL）之一。
   - **求值阶段**：施加读电流，通过四个 MTJ 的电阻分压确定输出，送入双输出敏感放大器得到互补逻辑结果（AND/NAND 或 OR/NOR）。
   - 通过重配置同一 LIM 阵列，可依次实现：乘法（AND）、最小（AND）、最大（OR）、绝对减法（XOR）、除法（MUX）、缩放加法（MUX）——即完整的 **ALU 功能套件**。

3. **比特流到二进制转换器（后端）**
   - 采用基于 LIM 的计数器实现，计算比特流中 '1' 的比例并转换回加权二进制表示。

### 关键意义
- 所有运算均为**串行逐比特处理**，周期数 O(N)（N 为比特流长度）。
- 每个比特权重相等，单个比特错误被平均到整个流上，实现天然容错。
- 处理完全在存储阵列内完成，无需将中间数据搬出到外部处理器。

## 6. 主要结论与发现

1. **SC 表示 + 确定性比特映射可实现精确计算**：基于 LD 模式的确定性编码产生的误差低于随机比特流，且计算精度随流长 N 增加单调提升（如 1024 位流乘法噪声为 0% 时 MAE 仅 0.86%）。
2. **FALCON 具有出色的噪声容限**：在高达 30% 的软错误注入下，各运算的 MAE 仍保持在约 15%~20% 的有限范围内，远优于二进制计算的灾难性失效。
3. **对工艺变化具有天然鲁棒性**：即使关键 FinFET/MTJ 参数发生 ±3σ、10% 的变化，所有运算功能输出依然正确；延迟/功耗虽有波动但无功能性失败。
4. **支持激进电压缩放**：从 0.9V 降至 0.7V 时，运算精度无劣化，功耗节省约 51%；0.8V 时节省约 27%——源于 SC 的概率表示对写入/读取电流变化的统计不敏感性。
5. **应用级验证成功**：形态学闭合在 30% 噪声下仍能取得 0.89 的 IoU（二值化图像），优于传统二进制 IMC 的 0.64。
6. **能效优势明显**：执行 256×256 形态学闭合仅消耗约 7.63μJ，预计比冯·诺依曼基线节省约 10 倍能量，主要归因于消除了片外数据搬运。

## 7. 优点

- **研究思路创新度高**：将 SC 的容错特性和 MTJ 的记忆/可重构特性系统性地融为一体，形成"端到端"的存内 ALU 设计，属于思路清晰且有说服力的架构级创新。
- **彻底消除了 SC 系统的经典瓶颈**：通过确定性 LD 比特映射与标准 MTJ 读写操作的天然结合，规避了 RNG 电路的面积、功耗和研究依赖——这是与所有既有 SC+IMC 方案（如 SCRIMP、SC-CRAM、Stoch-IMC）形成**根本差异**的亮点。

- **可靠性验证层次全面**：从逻辑/行为级软错误注入到晶体管级 HSPICE 工艺变化与电压缩放仿真，再到系统/应用级图像处理演示，证据链完整。
