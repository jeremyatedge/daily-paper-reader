## 摘要
大语言模型越来越多地部署在功率和面积预算紧张的边缘设备上。虽然混合精度GEMM降低了算术复杂度，但量化推理通常以反量化和非线性算子为主。基于查找表（LUT）的方法通过预计算输出并用查表替代重复算术来缓解这些开销，但现有设计会带来显著的容量和查找延迟开销。本文提出了PALUTE，一种基于LUT的处理-内存加速器，构建在单片3D DRAM上，用于高效的边缘大语言模型推理。PALUTE实现了DRAM内LUT查询，利用M3D DRAM存储阵列块的垂直组织，以低面积开销实现高并行性。近内存LUT生成器支持对GEMM和逐元素一元非线性算子的低延迟LUT生成，而系统级分层和调度策略最小化了跨内存层的数据移动。使用周期精确仿真和RTL综合的评估表明，PALUTE在0.16 W功耗下实现了1,264 TPS端到端吞吐量，相比于CHIME和FIGLUT，能效分别提升了12.8倍和1.6倍，在Qwen3-4B模型的W4A4配置下，相比于PIMPAL，面积效率提升了2.0倍。

## Abstract
Large language models are increasingly deployed on edge devices with tight power and area budgets. While mixed-precision GEMM reduces arithmetic complexity, quantized inference is often dominated by dequantization and nonlinear operators. Lookup Table (LUT)-based method mitigates these costs by precomputing outputs and replacing repeated arithmetic with table lookups, but existing designs incur significant capacity and lookup-latency overheads. This paper presents PALUTE, a LUT-based Processing-In-Memory accelerator built on Monolithic 3D DRAM for efficient edge LLM inference. PALUTE enables in-DRAM LUT queries that exploit the vertical organization of M3D DRAM memory array tiles to achieve high parallelism with low area overhead. A near-memory LUT generator supports low-latency LUT generation for both GEMM and element-wise unary nonlinear operators, while a system-level tiering and scheduling strategy minimizes data movement across memory tiers. Evaluation using cycle-accurate simulation and RTL synthesis shows that PALUTE achieves 1,264 TPS end-to-end throughput at 0.16 W, improving energy efficiency by 12.8$\times$ over CHIME and 1.6$\times$ over FIGLUT, improving area efficiency by 2.0$\times$ over PIMPAL under W4A4 across Qwen3-4B models.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：边缘大语言模型（LLM）推理受限于严格的功率和面积预算。混合精度量化虽然降低了算术复杂度，但 **反量化（dequantization）和非线性算子（如GELU、Softmax）开销巨大**，可占运行时的20-90%，抵消了低精度运算的优势。同时，现有基于查找表（LUT）的方法（如pLUTo、PIMPAL）虽能避免反量化，但面临 **LUT存储容量大、查询延迟高、并行度受限** 等问题，且大多未解决端到端流水线中的数据移动瓶颈。
- **整体含义**：需要一种能在内存中高效执行LUT查询的架构，既利用高并行性又降低面积开销，从而在边缘实现高性能、低功耗的LLM推理。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
基于**单片3D DRAM（M3D DRAM）**的LUT处理-内存（PIM）加速器PALUTE，通过**垂直存储阵列块（MAT）**实现高并行DRAM内LUT查询，配合**近内存LUT生成器**和**系统级数据分层调度**，消除反量化与非线性开销。

### 关键技术细节
- **LUT查询机制**：利用M3D DRAM的垂直位线（VBL）拓扑，将LUT条目横向存储于MAT中。每个MAT内，字线对应索引，位线垂直读出值。通过**半表（half-table）技术**，利用符号对称性只存储非负值，将LUT容量减半。查询时，匹配逻辑扫描所有行，并行返回多个LUT结果。
- **近内存LUT生成器**：位于逻辑die上，通过混合键合（hybrid bonding）与DRAM bank相连。包含GEMM核心和一元非线性核心。GEMM核心在**3个时钟周期**内枚举所有可能的权值组合与激活的乘积和，生成LUT条目；之后写回DRAM供查询。
- **数据分层与调度**：根据访问频率和延迟差异，将权重、初始token放在靠近逻辑die的低层（短字线），LUT放在中间层，KV缓存放在高层并靠近累加器，减少跨层数据移动。

### 公式/算法流程
- GEMM分解为小段点积：固定激活段 \(x_{seg}\)，遍历权值段 \(w_{seg}\) 的所有组合（4-bit权值共256种），预计算 \(x_{seg} \cdot w_{seg}\) 的256个结果存入LUT。推理时，权值作为索引直接查表得到部分和，累加得到最终结果。
- 非线性单元：对每个可能的输入值（如4-bit共16个）预计算GELU输出，输入作为索引查表。

## 7. 优点

- **创新性**：首次将**M3D DRAM的垂直结构**与**DRAM内LUT查询**相结合，利用垂直MAT实现极高并行度（最多8,388,608个并发查询），同时面积开销小。

- **系统级协同优化**：数据分层放置和调度策略最小化跨层数据移动，与LUT查询紧密配合。
- **评估全面**：包含四种SOTA基线、多模型规模、敏感度分析，并提供了RTL综合的开销数据。
