## 摘要
随着传感器通道数量的增加，系统在前端数据采集和植入式数据处理方面面临挑战。本文提出了一款32通道全事件驱动型植入式脑机接口SoC，采用65nm CMOS工艺，实现了高效的神经形态信号处理流水线。该SoC集成了32通道双阈值增量调制（DTDM）前端阵列，可提供高达26倍的前端数据压缩；存内计算（IMC）尖峰检测器（SPD）用于高效的像素内尖峰检测；以及基于双极性LIF的脉冲神经网络（Bi-SNN）解码器，用于片上运动意图解码（MID）。每通道功耗仅3.53微瓦，解码R²达到约0.62，每通道面积紧凑为0.034 mm²，该芯片为植入式设备实现了高效的信号记录、处理和解码。

## Abstract
With the scaling of sensor channel counts, systems confront challenges in frontend data sensing and on-implant data processing. This work presents a 32-channel fully event-based iBMI SoC in 65nm CMOS for an efficient neuromorphic signal processing pipeline. The SoC integrates a 32-channel dual-threshold delta modulation (DTDM) frontend array that provides up to 26x data compression at the frontend, an in-memory computing (IMC) spike detector (SPD) for efficient in-pixel spike detection, and a bipolar LIF-based spiking neural network (Bi-SNN) decoder for on-chip motor intention decoding (MID). Consuming only 3.53 μW per channel and achieving ~0.62 decoding R2 with a compact 0.034 mm2 per-channel area, the chip enables high-efficiency signal recording, processing, and decoding for implantable devices.

- **背景**：随着植入式脑机接口（iBMI）传感器通道数增加，前端数据率急剧上升，超过植入设备的无线传输能力。传统方案采用奈奎斯特ADC均匀采样，导致高能耗和高数据率；后续尖峰检测需要大缓存和密集计算；解码阶段也需要大量乘累加（MAC）操作。
- **核心问题**：如何实现高通道数、低功耗、低数据率的端到端片上信号处理和解码，满足下一代无线高密度iBMI需求。
- **整体含义**：本文提出一种**全事件驱动神经形态信号处理流水线**的SoC，从模拟前端到数字解码均采用事件驱动方式，大幅降低功耗、面积和数据率，为植入式设备提供可实用的高能效方案。

## 2. 论文提出的方法论：核心思想、关键技术细节
### 核心思想
- **事件驱动采样与处理**：利用神经信号的稀疏性，仅在信号变化时产生事件，实现前端压缩和后续异步处理。
- **双阈值增量调制（DTDM）**：结合粗阈值（抗噪声）和细阈值（高精度跟踪），适应噪声环境并保证重建精度。
- **存内计算尖峰检测器（IMC-SPD）**：将事件直接存储在eDRAM/SRAM位元中，通过存内逻辑实现计数和阈值比较，省去传统大容量缓冲器。
- **双极性脉冲神经网络（Bi-SNN）解码器**：采用LIF神经元实现三元激活（正/负/零），利用事件驱动特性减少MAC操作，同时降低功耗。

### 关键技术细节
1. **模拟前端（AFE）**：
   - 采用**斩波**技术抑制1/f噪声。
   - 采用**钳位T电容反馈网络**：通过T电容网络和钳位二极管，等效反馈电容降至$C_u/(2N+1)$，配合输入电容$M C_u$，实现高增益$M(2N+1)$，同时总电容减少64%（M=30，N=1）。
   - **两级电流复用OTA**：在0.5倍功耗下实现2倍开环增益。
2. **双阈值增量调制（DTDM）**：
   - 模拟输出与两个阈值窗口比较：粗阈值$V_{th1}=V_{H1}-V_{L1}$，细阈值$V_{th2}=V_{H2}-V_{L2}$。
   - 当信号越过粗阈值时产生事件并复位；无事件时使用粗阈值抑制噪声；当检测到活动时切换到细阈值提高跟踪精度。
   - 时间窗口设置为1.5 ms以平衡响应速度和噪声稳定性。
3. **存内尖峰检测器（IMC-SPD）**：
   - 每通道包含8个ON单元和8个OFF单元，每个单元处理$T_s=125\mu s$，总滑动窗口1 ms。
   - 采用**eDRAM辅助事件锁存器**：事件电荷存入eDRAM电容，在$T_s$结束时二值化并锁存防止泄漏；通过共享检测线读取计数，映射为脉冲数后与数字阈值比较。
   - 相比先前的片外AER尖峰检测器，可同时滤除噪声事件并减少AER握手开销。
4. **双极性脉冲神经网络（Bi-SNN）解码器**：
   - 网络结构：32-48-2（输入32通道，隐藏层48个BiLIF神经元，输出层2个LIF神经元预测2D速度）。
   - 输入帧缓冲区以250 Hz采样，存储每通道尖峰模式（32 bits）。
   - **BiLIF神经元**：采用位移位泄漏路径（右移$L_{bit}$）模拟指数泄漏，使用减法器实现；通过正/负/零三元激活编码膜电势动态。
   - **事件驱动低功耗模式**：空闲时使用较低电源，仅ACK和缓冲AER输入帧，减少开关活动。

## 7. 优点
1. **全事件驱动流水线**：从ADC（DTDM）到尖峰检测（IMC-SPD）到解码（Bi-SNN）均采用异步事件触发，避免均匀采样带来的冗余数据和能耗。
2. **双阈值增量调制**：创新性地分离粗阈值（抗噪）和细阈值（精度），在不牺牲压缩率的情况下提升噪环境下的信号恢复质量。
3. **存内尖峰检测器**：利用eDRAM临时存储事件，通过存内计数直接输出检测结果，省去传统数字缓冲器（减少9.5×缓冲区大小），且与AER接口自然兼容。
4. **双极性LIF神经元**：采用位移位泄漏和三元激活，硬件实现极简（避免乘法器），事件驱动特性使MAC数量减少23.4×。
5. **低功耗与小面积**：每通道3.53 μW和0.034 mm²，远超表I中多数SoC（多数>5 μW/通道且面积>0.1 mm²）。
