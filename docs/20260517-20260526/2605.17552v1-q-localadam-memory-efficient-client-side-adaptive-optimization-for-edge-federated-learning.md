## 摘要
边缘设备上的联邦学习必须应对非独立同分布（non-IID）的客户端数据和有限的内存预算。像Adam这样的自适应优化器可以在数据异质性下稳定训练，但需要存储全精度的动量和方差状态，这通常会使客户端内存开销增加三倍。这限制了在资源受限设备上可部署的模型大小和并发联邦任务。我们通过实验观察到，联邦Adam中的动量和方差表现出根本不同的统计特性：动量值对称且有界，而方差跨越八个数量级，具有对数正态结构。受这种不对称性的启发，我们提出了Q-LocalAdam，它对动量应用基于分布感知的8位量化块状线性编码，对方差应用对数空间编码，同时保持模型参数为全精度。在CIFAR-10和CIFAR-100上，在不同的数据异质性（α∈{0.1, 0.5, 1.0, IID}）下，Q-LocalAdam在中等异质性下实现了3.37倍的优化器内存缩减且无精度损失，在极端异质性下则显著提升（例如，在CIFAR-100上，α=0.1时提升了5.74个百分点）。多种子验证确认了统计显著性（p<0.01）。相比之下，简单的均匀量化会退化到随机性能，这表明基于分布感知的设计至关重要。Q-LocalAdam使得在内存受限的边缘设备上能够部署更大的模型和更多的并发工作负载，而无需修改联邦协议。

## Abstract
Federated learning on edge devices must cope with non-IID client data and tight memory budgets. Adaptive optimizers like Adam stabilize training under data heterogeneity but require storing full-precision momentum and variance states, often tripling client memory overhead. This limits deployable model sizes and concurrent federated jobs on resource-constrained devices.   We empirically observe that momentum and variance in federated Adam exhibit fundamentally different statistical properties: momentum values are symmetric and bounded, while variance spans eight orders of magnitude with log-normal structure. Motivated by this asymmetry, we propose \textbf{Q-LocalAdam}, which applies distribution-aware 8-bit quantization block-wise linear encoding for momentum and log-space encoding for variance while keeping model parameters in full precision.   Across CIFAR-10 and CIFAR-100 under varying data heterogeneity ($α\in \{0.1, 0.5, 1.0, \text{IID}\}$), Q-LocalAdam achieves $3.37\times$ optimizer memory reduction with no accuracy loss under moderate heterogeneity and significant improvements under extreme heterogeneity (e.g., +5.74pp on CIFAR-100, $α=0.1$). Multi-seed validation confirms statistical significance ($p<0.01$). In contrast, naive uniform quantization degrades to random performance, demonstrating that distribution-aware design is essential. Q-LocalAdam enables larger models and more concurrent workloads on memory-constrained edge devices without modifying the federated protocol.

- **问题**：能否在不牺牲非IID鲁棒性的前提下，大幅减少客户端侧优化器内存？
- **现有方案局限**：服务器端自适应优化（如FedAdam）可减少客户端内存，但客户端侧自适应优化（如Vanilla-ClientAdam）在本地多epoch训练中更有效，且去中心化/多任务场景无法使用服务器优化。已有的通信压缩方法不解决客户端内存瓶颈。
- **本文目标**：提出Q-LocalAdam，通过分布感知的8位量化压缩优化器状态，保持模型参数全精度，不修改联邦协议，实现3.37倍内存缩减且无精度损失。

## 2. 方法论
### 核心思想
- **关键观察**：在联邦Adam训练中，动量（m）对称有界（±0.1），近似高斯分布；方差（v）跨越7-8个数量级（10⁻¹²~10⁻³），呈对数正态分布。统一线性量化会失败，因此需对不同状态采用不同量化方案。

### 关键技术细节
- **块状量化**：将动量/方差张量划分为固定大小块（默认B=64），每块独立使用8位量化。
- **动量量化（线性）**：
  - 对每块计算min、max，线性映射到[0,255]整数。
  - 公式：\( q^{(b)} = \lfloor \frac{m^{(b)} - \min^{(b)}}{\max^{(b)} - \min^{(b)}} \times 255 \rceil \)
  - 反量化：\(\tilde{m}^{(b)} = \frac{q^{(b)}}{255} \times r^{(b)} + \min^{(b)}\)
- **方差量化（对数空间）**：
  - 先对\(v+\epsilon\)取对数，再进行线性量化（保持跨数量级的相对精度）。
  - 公式：\( \ell^{(b)} = \log(v^{(b)}+\epsilon) \)，然后对\(\ell^{(b)}\)线性量化，反量化后指数还原。
- **内存布局**：每块存储B个INT8值（1字节/个）+ 2个FP32标量（min/max或log_min/log_max）= 共(B+8)字节。对于B=64，每块72字节 vs FP32 256字节，理论压缩比3.56倍，实际（含填充对齐）为3.37倍。
- **算法流程**（Algorithm 1）：每个客户端每轮开始时初始化量化状态；在每个本地更新步中：反量化状态→FP32更新Adam公式→再量化状态→用FP32进行偏置校正和参数更新。服务器仅做加权平均（FedAvg），不修改协议。

## 3. 实验设计
### 数据集与场景
- **数据集**：CIFAR-10（10类，50K训练/10K测试）和CIFAR-100（100类）。
- **数据异质性**：使用Dirichlet分布（α∈{0.1, 0.5, 1.0, IID}）将训练数据划分给10个客户端。α越小异质性越强（如α=0.1时，CIFAR-10部分客户端单类占比超90%）。
- **模型与训练**：ResNet-18（CIFAR-10 6.3M参数，CIFAR-100 11M参数）。输入上采样至224×224模拟真实迁移学习。训练120轮，每轮随机选5个客户端，每个客户端2个本地epoch，batch size 64。优化器：Vanilla-ClientAdam（β1=0.9, β2=0.999, ε=1e-8, lr=1e-3）。

### 对比方法
- **Baselines**：
  - Vanilla-ClientAdam (FP32)：全精度基线。
  - Naive INT8：对动量和方差都使用均匀线性8位块状量化（类似Dettmers的8-bit Adam但直接用于联邦）。
- **Ablations**：
  - Momentum-only：仅量化动量（线性），方差FP32。
  - Variance-only：仅量化方差（对数空间），动量FP32。
  - 不同块大小（B=32,64,128）和不同学习率（1e-3, 5e-4）

## 6. 主要结论与发现
1. **内存缩减**：Q-LocalAdam在CIFAR-10上优化器内存从50.35 MB降至14.95 MB，CIFAR-100上从89.82 MB降至26.67 MB，实现3.37倍压缩。
2. **精度保持或提升**：在中等异质性（α≥0.5）下，Q-LocalAdam与FP32准确率相当（如CIFAR-10 α=0.5：87.44% vs 87.33%）；在极端异质性（α=0.1）下，显著提升：CIFAR-100提升+5.74pp（61.47% vs 55.73%），统计显著（p<0.01）。

4. **对数空间量化稳定**：反复量化/反量化未导致发散，EMA平滑了量化噪声。
5. **组件必要性**：同时量化动量和方差达到最优精度-内存折衷；部分量化仅1.5-1.8x压缩且CIFAR-100上精度下降（动量单独量化仅52.49%）。
6. **鲁棒性**：块大小（B=32~128）和学习率（1e-3 vs 5e-4）敏感度低，默认B=64表现最佳。

## 7. 优点
