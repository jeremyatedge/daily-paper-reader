## 摘要
超维计算（HDC）是一种有前景的边缘能效机器学习（ML）方法，其中低延迟、低功耗和严格的内存预算至关重要。然而，传统的HDC依赖于符号绑定和伪随机的高维向量，这需要大维度和启发式更新才能达到竞争性的准确度，从而限制了在边缘硬件上的部署。我们提出了XL-HD，这是一种确定性的、基于投影的、完全可学习的HDC框架，专为边缘计算系统中的内存加速而定制。该方法使用固定的Sobol序列投影二进制输入，将学习扩展到传统HDC之外。在训练过程中，类别原型在实值空间中进行优化，随后进行二值化，从而实现了完全二值化的点积推理流程，非常适合诸如ReRAM交叉阵列等IMC硬件。XL-HD在MNIST、UCIHAR和ISOLET上达到了竞争性的准确度，同时保持了紧凑的基于IMC的推理引擎，面积仅为0.395 mm²，每次单周期推理仅消耗0.40 μJ。

## Abstract
Hyperdimensional computing (HDC) is a promising approach for energy-efficient edge machine learning (ML), where low latency, low power, and tight memory budgets are essential. However, traditional HDC relies on symbolic binding and pseudo-random high-dimensional vectors, which require large dimensionality and heuristic updates to reach competitive accuracy, limiting deployment on edge hardware. We introduce XL-HD, a deterministic, projection-based, fully learnable HDC framework tailored for in-memory acceleration within edge computing systems. The method uses a fixed Sobol sequence to project binary inputs, extending learning beyond conventional HDC. During training, class prototypes are optimized in real-valued space and later binarized, enabling an entirely binary dot-product inference pipeline ideal for IMC hardware such as ReRAM crossbars. XL-HD achieves competitive accuracy on MNIST, UCIHAR, and ISOLET while maintaining a compact IMC-based inference engine with $0.395 \ \text{mm}^2$ area and only $0.40 \ μ\text{J}$ per single-cycle inference.

- **核心问题**：传统超维计算（HDC）方法依赖符号绑定和伪随机生成的高维向量，导致两个关键瓶颈：
  - 精度与硬件效率的冲突：在采用1-bit编码时，为保持分类精度，必须将向量维度提升至4K–8K，大幅增加了存储与计算开销。
  - 伪随机向量空间分布不均匀，需要更大维度才能实现类间可分离性，不适合边缘设备严格的面积、功耗和延迟约束。
- **整体含义**：为在资源受限的边缘设备上（尤其是内存计算加速器）实现高效且接近深度学习水平的机器学习推理，需要重新设计HDC流程，将确定性、低维度和完全的二进制表示融入算法-硬件协同设计。

## 2. 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：用固定、确定性的低差异序列（Sobol序列）代替伪随机投影矩阵，将输入特征线性映射到高维空间；在此空间内学习可微的类原型（实值），训练后二值化；使整个推理流水线（编码+分类）仅包含二进制点积运算，完全适配ReRAM交叉阵列的原位计算。

- **关键技术细节**：
  1. **确定性投影**：构造一个固定矩阵 **P** = Φ_Sobol(D, F)，元素经阈值0.5后变为±1。输入特征向量 **x** ∈ ℝ^F通过简单线性映射 **h** = **Px** 得到超向量。
  2. **可学习类原型**：初始化类原型为同类样本编码超向量的累加均值；训练时使用余弦相似度 + 交叉熵损失，通过梯度下降精炼实值原型；训练完成后将原型二值化。
  3. **硬件映射**：将投影矩阵 **P** 分解为两个二值掩膜（+1和-1），分别存入正/负两个ReRAM交叉阵列；输入经二值化后驱动字线，通过检测位线电流比较实现原位二值化；分类时，查询超向量与二值化类原型在另一组交叉阵列中执行二进制点积。

- **算法流程（文字说明）**：
  1. 使用Sobol序列生成固定投影矩阵 **P**（D×F），并二值化为±1。
  2. 对所有训练样本计算编码超向量 **h** = **Px**。
  3. 累加同类超向量初始化类原型 **C**。
  4. 对每个mini-batch，计算编码向量与 **C** 的余弦相似度，经softmax得到概率，使用交叉熵损失。
  5. 通过梯度下降更新 **C**（实值）。
  6. 训练后将 **C** 二值化（阈值0.5）。
  7. 推理：对查询样本执行确定性的Sobol投影→原位二值化→与二值化类原型的点积→取最大相似度的类。

## 7. 优点

- **算法-硬件协同设计**：彻底将传统HDC的符号绑定操作为线性VMM，直接映射到交叉阵列，消除了冗余逻辑和多次内存访问。
- **确定性低维编码**：使用Sobol序列替代伪随机，在同等精度下可将维度从数K降低至数十到几百，大幅降低硬件开销。
- **全二进制推理流水线**：从输入到输出均为1-bit表示，无需ADC/DAC，适合低功耗边缘设备。
- **可学习类原型**：利用梯度下降精炼，比传统累加式更准确，同时保持推理阶段的二进制操作。
