## 摘要
随着边缘计算的发展，在单个共享 GPU 上提供多个深度神经网络（DNN）模型服务已成为一种常见但具有挑战性的场景，其中每个调度决策都会影响所有并发队列的尾部延迟。现有的调度器依赖于局部启发式方法，无法捕捉这种全局影响，而 GPU 空间共享方法则牺牲了延迟的可预测性。在本文中，我们提出了 EdgeServing，一种针对边缘设备的截止时间感知多 DNN 服务系统。EdgeServing 采用带有早退推理（early-exit inference）的时分 GPU 共享机制以实现高推理可预测性，并引入了稳定性评分来量化每个候选调度决策对未来队列状态的影响。在运行时，它协同选择模型、退出点和批处理大小，以最小化预测的全系统服务水平目标（SLO）影响。在多个硬件平台上的实验结果表明，EdgeServing 在 SLO 违规率和 P95 延迟方面均始终优于代表性的基准方法，这得益于早退机制在严格的延迟约束下扩展了调度动作空间。

## Abstract
As edge computing expands, serving multiple deep neural network (DNN) models on a single shared GPU has become a common yet challenging scenario, where each scheduling decision affects the tail latency of all concurrent queues. Existing schedulers rely on local heuristics and fail to capture this global impact, while GPU spatial-sharing approaches sacrifice latency predictability. In this paper, we propose EdgeServing, a deadline-aware multi-DNN serving system for edge devices. EdgeServing adopts time-division GPU sharing with early-exit inference for high inference predictability, and introduces a stability score to quantify how each candidate scheduling decision impacts the future queue status. At runtime, it cohesively selects the model, exit point, and batch size to minimize predicted system-wide SLO impact. Experimental results on multiple hardware platforms show that EdgeServing consistently outperforms representative baselines in both SLO violation ratio and P95 latency, enabled by early-exit mechanism, which expands the scheduling action space under tight latency constraints.

### 2. 方法论：EdgeServing 系统设计
EdgeServing 结合了**时分 GPU 共享**和**早退（Early-exit）机制**，核心思想是通过预测未来状态来做出最优调度决策。

    *   **离线分析（Offline Profiler）**：预先测量不同模型、不同退出点（Exit Point）和不同批处理大小（Batch Size）在目标硬件上的推理延迟和精度，生成配置表。

    *   **在线调度算法**：在每个调度周期，调度器会遍历所有候选决策（模型、退出点、批处理大小），预测执行该决策后所有队列的新状态，计算全局稳定性评分，最终选择使**系统总稳定性评分最低**（即全局最稳健）的决策。
    *   **协同优化**：同时决定“服务哪个模型”、“用哪个退出点以节省时间”以及“批处理多少请求以提高吞吐”。

*   **SLO 保障**：在重负载下，EdgeServing 的 SLO 违规率保持在 1% 以下，而 All-Final 基准在相同条件下违规率超过 15%。

*   **自适应性**：系统能根据流量压力自动切换退出点。低负载时使用深层退出点保证精度（约 77%），高负载时自动切换至浅层退出点以牺牲精度换取生存空间。

### 7. 优点与亮点
*   **全局视角**：不同于以往只看当前任务的调度器，EdgeServing 考虑了“当前决策对其他所有队列的负面影响”，这种全局稳定性建模非常新颖。
*   **多维搜索空间**：将早退机制引入调度决策，极大地扩展了系统在极端负载下的调节能力。
*   **高预测性**：坚持使用时分共享而非空间共享，虽然看似保守，但在边缘端为 SLO 提供了极其重要的确定性。

### 8. 不足与局限
*   **精度损失风险**：在极高负载下，为了满足延迟要求，系统会频繁从 layer1 退出，导致精度大幅下降（实验中最低降至约 7%），这在某些安全敏感场景下可能不可接受。
*   **离线剖析依赖**：系统高度依赖离线 Profile 的准确性。如果运行时环境发生剧烈变化（如 GPU 温度过高导致降频），预设的延迟表将失效。
*   **模型结构限制**：虽然声称模型无关，但实验仅基于 ResNet 系列。对于难以添加早退分支或分支开销过大的模型，该方法的收益会受限。
