## 摘要
高粒度量化（HGQ）利用权重级量化和剪枝来设计资源高效的神经网络加速器，在精度与硬件利用率之间实现了有吸引力的权衡。HGQ特别适用于基于FPGA的边缘神经网络应用。标准HGQ工作流程从高精度模型开始，在梯度优化引导下逐步降低位宽，以勾勒帕累托前沿。这种单调且不可逆的剪枝过程计算密集，且可能忽略给定资源水平下的最优子网络。我们提出了一种资源导向的一次性量化器剪枝方法，将网络直接接近目标搜索空间，然后使用双向β调度进行微调，以实现对帕累托前沿更精细的扫描。在喷注子结构分类（JSC）任务上验证，我们的方法相比标准HGQ工作流中的单调资源减少，将搜索成本降低了最多20.58倍，同时实现了具有竞争力的帕累托前沿和最终网络配置。

## Abstract
High granularity quantisation (HGQ) exploits weight-level quantisation and pruning to design resource-efficient neural network accelerators, achieving an attractive trade-off between accuracy and hardware utilisation. HGQ is particularly well suited to FPGA-based edge neural network applications. Standard HGQ workflow starts from a high-precision model and progressively reduces bit width, guided by gradient-based optimisation to outline the Pareto frontier. This monotonic and irreversible pruning process is computationally intensive and can overlook the optimal subnetwork for a given resource level. We propose a resource-oriented one-shot quantiser pruning method that brings the network directly close to the target search space, and then use bidirectional beta scheduling for fine-tuning to enable a more refined scan of the Pareto frontier. Validated on the jet substructure classification, JSC, task, our method reduces the search cost by up to 20.58x compared with monotonic resource reduction in standard HGQ workflows, while achieving a competitive Pareto frontier and final network configuration.

- **现有方法**：高粒度量化（HGQ）通过在训练中优化每个权重的位宽，结合可微资源代理（EBOPs），实现精度与资源利用率的帕累托最优。但标准 HGQ 工作流从高精度模型**单调、不可逆地逐步降低位宽**，计算密集且可能因路径依赖而错过给定资源预算下的最优子网络。
- **核心问题**：如何在不损失精度和资源效率的前提下，大幅降低 HGQ 搜索成本，并避免陷入次优子网络。

## 方法论：核心思想、关键技术细节、算法流程

- **核心思想**：提出**资源导向的一次性量化剪枝（Resource-Oriented Quantiser Pruning, RQP）**，将预训练的高资源模型一次性“投影”到目标资源预算附近，然后通过**双向β调度**在目标区域进行精细搜索，取代单调压缩过程。
- **关键技术细节**：
  1. **一次性量化剪枝（One-shot Quantiser Pruning）**：
     - 操作对象是**连续型量化器位宽**（而非传统离散的二进制权重掩码），实现更细粒度的资源剪枝。
     - 步骤：
       - **目标预算位宽重分配（Algorithm 1）**：根据预训练模型的当前资源 E_cur 与目标预算 E⋆，计算全局压缩比 α，再结合逐层统计量（平均位宽）得到层缩放因子，将每层位宽矩阵缩放到有效范围。
       - **谱约束拓扑补偿**：为改善剪枝后子网络的可训练性，通过结构得分（权重幅度×位宽）选择连接，并利用**条件数约束**修复病态子网络（式 3），确保梯度路径稳定；最后用全局标量 λ 微调位宽使实际资源匹配 E⋆。
  2. **双向β调度（Bidirectional β Scheduling, Algorithm 2）**：
     - 维护一个资源压力系数 β，在每个训练 epoch 后根据观测资源 E_obs 与目标 E⋆ 的偏差动态调整 β：若资源偏高则增加 β（施加更大压缩压力），偏低则降低 β；调整强度由预算比平方根控制，保持稳定性。
     - **外循环防死锁机制**：当验证性能在 S 个 epoch 内停滞时，认为进入“β 死锁”（量化器被压低到低比特范围后难以重新激活），通过线性松弛 β 到下限 β_lo 来释放压缩压力，从而跳出次优拓扑，实现退火式的近目标搜索。

## 主要结论与发现

1. **搜索效率大幅提升**：RQP 在相同 epoch 数（6k epoch）下，搜索成本相比 HGQ 200k epoch 降低 **20.58×**，且精度超越同等 epoch 的 HGQ，验证了一次性量化剪枝在资源投影上的高效性。
2. **近目标精细搜索优势**：双向β调度能够克服单调压缩的路径依赖和锁死效应，在目标资源附近获得更密的帕累托前沿，且最终子网络往往优于 HGQ 的单调搜索结果。
3. **硬件指标提升**：RQP 得到的网络在 FPGA 上可实现更高的最大频率（如 400 EBOPs 点从 662 MHz 提升到 671 MHz），且延迟（ns）更优，说明位宽分布更有利于时序。
4. **精度保持或超越**：在所有对比资源水平上，RQP 的测试精度不低于甚至超过 HGQ 的最佳结果（如 400 EBOPs 点，RQP 为 73.87%，HGQ 200k epoch 为 73.64%）。

## 优点

- **方法创新**：将一次性剪枝从离散二进制掩码扩展到连续量化器位宽，并引入谱约束保持可训练性，思路新颖。
- **效率增益显著**：直接投影到目标资源，跳过大量冗余中间阶段，训练时长减少一个数量级以上，对实际部署非常有价值。
- **反死锁机制**：双向β调度中的外循环松弛有效避免压缩锁死，使网络能跳出次优拓扑，提升搜索质量。
- **全面验证**：在算法层面（精度、资源匹配度）和硬件层面（LUT、延迟、频率）均进行了评估，且提供了消融实验。
