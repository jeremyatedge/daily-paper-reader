## 摘要
在边缘平台上部署视觉Transformer（ViT）模型仍具有挑战性，原因是其高计算需求和现代混合ViT模型的架构异构性——这类模型同时包含全连接层和卷积层。这种异构性导致张量形状的显著变化，从而需要灵活高效的基于FPGA的加速方案。本文提出FlexViT，一种可重构的FPGA加速器，用于在资源受限的边缘设备上进行高效的ViT推理。基于SECDA-TFLite框架，FlexViT采用硬件-软件协同设计方法，通过运行时im2col变换将全连接层和卷积层映射到统一的、高吞吐量的INT8通用矩阵乘法（GEMM）引擎上。为高效支持多样化的层配置，我们提出一种双模式数据流，通过在运行时对计算阵列进行重构，动态切换输入与权重的重用模式。我们进一步引入深度优先的分块策略，在一次遍历中完成累加，从而消除片外部分和传输，降低内存带宽需求。我们在PYNQ-Z2 FPGA上实现了FlexViT，并在多种代表性ViT模型上进行了评估。在加速器执行的层上，FlexViT实现了最高2.74倍的加速，与纯CPU执行相比，端到端加速比最高达1.40倍。代码开源在：https://github.com/gicLAB/FlexViT

## Abstract
Deploying Vision Transformer (ViT) models on edge platforms remains challenging due to their high computational demands and the architectural heterogeneity of modern hybrid ViT models, which incorporate both fully connected and convolutional layers. This heterogeneity leads to significant variation in tensor shapes, requiring flexible and efficient FPGA-based acceleration. In this paper, we present FlexViT, a reconfigurable FPGA accelerator for efficient ViT inference on resource-constrained edge devices. Built on the SECDA-TFLite framework, FlexViT employs a hardware-software co-design approach that maps both fully connected and convolutional layers onto a unified high-throughput INT8 GEMM engine using a runtime im2col transformation. To efficiently support diverse layer configurations, we propose a dual-mode dataflow that dynamically switches between input and weight reuse by reconfiguring the compute array at runtime. We further introduce a depth-first tiling strategy that completes accumulation in a single pass, eliminating off-chip partial-sum transfers and reducing memory bandwidth requirements. We implement FlexViT on a PYNQ-Z2 FPGA and evaluate it across a representative set of ViT models. FlexViT achieves up to 2.74x speedup on accelerator-executed layers, translating into up to 1.40x end-to-end speedup compared to CPU-only execution. The code is available at: https://github.com/gicLAB/FlexViT

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：边缘设备上部署 Vision Transformer（ViT）模型面临两大挑战：① 计算需求高（参数量大、矩阵运算密集）；② 现代混合 ViT（如 MobileViT、EfficientViT）同时包含全连接层（FC）和卷积层（CONV），导致张量形状显著变化，现有的 FPGA 加速器通常只针对其中一种计算模式优化，缺乏灵活性。
- **背景**：FPGA 因其可重构性和并行性适合边缘 AI，但资源受限（如 PYNQ‑Z2 仅有少量 BRAM 和 DSP）。现有工作如 ViTA、M²ViT 等或因不支持混合架构、或依赖高端 FPGA 平台，难以直接用于低成本边缘设备。
- **目标**：设计一个**灵活、可重构**的 FPGA 加速器，能在资源受限边缘设备上高效支持标准 ViT 和混合 ViT 的端到端推理。

## 2. 方法论：核心思想、关键技术细节
- **统一 GEMM 映射**：基于 SECDA‑TFLite 框架，通过运行时 **im2col** 变换将 CONV 层线性化为矩阵乘法，从而将 FC 和 CONV 层统一映射到单个高吞吐 INT8 GEMM 引擎。
- **双模式数据流（Dual‑mode Dataflow）**：针对层形状差异，动态选择：
  - **输入广播模式（Input‑Broadcast）**：输入 tile 广播到所有核心，权重分区（适用于宽输出层，如 FC）。
  - **权重广播模式（Weight‑Broadcast）**：权重 tile 广播，输入分区（适用于窄输出层，如 CONV 的 “tall‑skinny” 矩阵）。
  - 选择策略：FC 层用宽度启发式，CONV 层用低 DMA 流量估计（Algorithm 1）。
- **深度优先分片（Depth‑first Tiling）**：将 per‑core tile 大小设为 TN=64、TM=64，最大缓冲深度 TK=1024，保证单次遍历完成累加，**消除片外部分和传输**，降低内存带宽压力。
- **硬件结构**（图 2a）：
  - **调度器**：动态控制双模式数据流和外/内循环顺序。
  - **读取单元**：四个独立 AXI 流（元数据、输入、权重、偏置），实现数据预取与计算重叠。
  - **GEMM 引擎**：3 个并行核心（C=3），每核心采用 SIMD 宽度 Kf=16 的向量处理单元，输出固定数据流，局部寄存器累加 32 位部分和。
  - **后处理单元（PPU）**：流水线化的偏置加法、重量化（FC 用 per‑tensor，CONV 用 per‑channel），最终输出 INT8 结果。
- **量化**：完全 INT8 量化，硬件直接支持。

## 6. 主要结论与发现
- **层级别加速**：FC/CONV 层加速 1.77× ~ 2.74×（最高为 DeiT‑T 的 2.74×）。
- **端到端加速**：1.24× ~ 1.40×（最高为 ViT‑T 和 DeiT‑T 的 1.40×）。
- **能量效率**：大部分模型能量几乎不变或略优（最高 1.09× 节能），仅在 EfficientViT‑b1 上能量比 CPU 增加约 7%（0.93×），原因是非加速操作占 59%，CPU+FPGA 双活跃导致静态功耗叠加。
- **瓶颈**：混合 ViT 的非加速操作（Softmax、LayerNorm、Reshape 等）占比超 50%，端到端加速被 Amdahl 定律制约。
- **统一 GEMM 架构的有效性**：成功支持所有测试模型，无需定制数据路径。

## 7. 优点
- **高度灵活**：通过动态数据流模式和统一 GEMM 引擎，单一硬件同时适配 FC 和 CONV 层，覆盖标准与混合 ViT。
- **资源高效**：在低端 PYNQ‑Z2 上利用 83.9% BRAM 和 71.8% DSP 实现单次遍历，避免片外部分和，适合边缘设备。
- **开源完整系统**：代码、框架（SECDA‑TFLite）、硬件设计全部公开，可复现。
- **系统级实测**：基于真实 TFLite 运行时和端到端推理，结果可靠。

## 8. 不足与局限
- **非加速操作成为瓶颈**：未加速 Softmax、LayerNorm、Embedding 等操作，导致混合 ViT 端到端加速有限。如果未来这些操作也比例增大，需要专用硬件支持。
- **资源受限导致并行度有限**：仅 3 个核心，无法充分开发大型矩阵的并行性；若用更大 FPGA（如 ZCU102）可扩展，但本文未验证。
- **能量权衡**：在非加速操作占比较大的模型中，能量略有增加，不适合对能耗极度敏感的场景。
- **对比缺失**：未在相同硬件上复现并对比其他 ViT 加速器（如 ViTA、M²ViT），仅通过资源比较定性论证优势。
