## 摘要
视觉Transformer通过自注意力机制捕捉图像区域的全局上下文，重塑了计算机视觉领域。这使得它们在可再生能源基础设施、工业质量控制、医学成像和自主系统传感等应用的边缘视觉检测与监控中具有吸引力。然而，在小型FPGA上部署ViT仍具有挑战性，因为自注意力中的softmax阶段需要进行指数评估和归一化，这在硬件上成本高昂。现有实现通常依赖于CORDIC流水线或基于BRAM的查找表，增加了面积和功耗。本文提出了一种无BRAM的近似注意力权重单元，用于基于FPGA的ViT推理。所提出的设计使用完全由分布式LUT逻辑实现的16段分段线性函数来近似softmax中的自然指数。与基2近似不同，自然指数形式保留了预训练的注意力温度，并避免了模型特定的重新校准。在Xilinx Zynq-7020上实现后，完整的注意力行核心使用了1444个LUT、77个DSP，且无BRAM，硬件精确仿真显示，与ViT系列模型上的精确softmax参考相比，其top-1绝对准确率差异在0.20%以内。这些结果证明了所提出的核心在资源受限的边缘AI平台上实现能效ViT推理的潜力。

## Abstract
Vision Transformers have reshaped computer vision by using self-attention to capture global context across image regions. This makes them attractive for edge visual inspection and monitoring in applications such as renewable-energy infrastructure, industrial quality control, medical imaging, and autonomous-system sensing. However, deploying ViTs on small FPGAs remains challenging because the softmax stage in self-attention requires exponential evaluation and normalization, which are costly in hardware. Existing implementations often rely on CORDIC pipelines or BRAM-based look-up tables, increasing area and power consumption. This paper presents a BRAM-free approximate attention-weighting unit for FPGA-based ViT inference. The proposed design approximates the natural exponential in softmax using a 16-segment piecewise-linear function implemented entirely with distributed LUT fabric. Unlike base-2 approximations, the natural-exponential formulation preserves the pre-trained attention temperature and avoids model-specific recalibration. Implemented on a Xilinx Zynq-7020, the complete attention-row core uses 1444 LUTs, 77 DSPs, and no BRAM, while hardware-accurate emulation shows accuracy within a \(0.20\%\) absolute top-1 difference from the exact-softmax reference on ViT-family models. These results demonstrate the potential of the proposed core for energy-efficient ViT inference on resource-constrained edge-AI platforms.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：Vision Transformer（ViT）在边缘设备上的部署面临挑战，因为自注意力机制中的softmax阶段需要指数运算和归一化，在FPGA上实现成本高（面积大、功耗高）。现有方案依赖CORDIC流水线或BRAM查找表，进一步加剧资源消耗。
- **动机**：边缘AI（如可再生能源基础设施监控、工业质检、医学影像）要求低功耗、低资源占用。尤其是可持续性场景中，大量设备长期运行，能耗成为关键约束。作者旨在设计一种无BRAM、低资源、高能效的近似注意力权重单元，使ViT能在小型FPGA上高效推理。
- **整体含义**：本文提出用分布式LUT逻辑实现16段分段线性（PWL）函数近似自然指数，替代softmax中的指数和归一化，无需模型重新校准，在保持精度接近精确softmax的同时，大幅降低硬件成本和功耗。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：利用softmax的数值稳定形式（max-centered），使输入uj ≤ 0，从而将指数输入限制在[-8, 0]区间。在该区间上用16段均匀PWL函数近似自然指数e^x，完全用分布式LUT实现，避免BRAM。
- **关键技术细节**：
  - **PWL近似**：在[-8, 0]上均匀划分16段，每段宽度0.5。边界点bi = -8 + 0.5i，存储17个边界值yi = e^{bi}（16位定点数，共272位，存储在LUTRAM中）。对输入x，直接计算插值：˜e(x) = yi + α(y_{i+1} - yi)，其中α为段内分数偏移。
  - **硬件架构**：完整的注意力行核心包含5个模块：得分计算MAC、PWL权重单元、分母累加器、分子累加器（权重×值向量）、串行化16位恢复除法器。采用两遍调度：第一遍计算所有点积得分并跟踪行最大值；第二遍重放每个token，计算近似权重并累加分子分母。
  - **精度保留**：直接近似自然指数，而非用基2替换（2^x = e^{x ln2}），避免了隐式的logit缩放，无需模型特定的温度校准。
- **算法流程**（文字说明）：
  1. 对查询q与每个键kj计算缩放点积得分sj。
  2. 找出行最大得分，得到max-centered得分uj = sj - max(sl)，确保uj ≤ 0。
  3. 将uj裁剪到[-8, 0]，用16段PWL计算近似指数˜e(uj)。
  4. 累加分母sum_exp = Σ ˜e(uj)，分子sum_weighted_value = Σ ˜e(uj) vj。
  5. 输出o = sum_weighted_value / sum_exp。
